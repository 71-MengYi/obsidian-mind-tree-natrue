# Mind Tree Nature

> 让你的笔记结构随思维自然成型。

Mind Tree Nature 是一款**离线优先**的 Obsidian 思维导图插件。它以 `.mtn.md` 文件为载体，在自定义视图里组织笔记、文本、图片、附件和网页链接，同时始终保留一份普通 Markdown 编辑器和 AI 都能直接读取的无序列表大纲。

- **五种布局**：均衡、向右、向左、树形、放射
- **十套主题**：明暗自适应，十二色按一级分支循环
- **桌面端与移动端**均可使用，触屏手势完整支持
- **界面双语**：简体中文 / English，跟随 Obsidian 界面语言

## 设计理念

**结构归导图，内容归文件。** 插件不试图替代 Markdown，而是给已有的库加一层可视化组织：导图负责层级与顺序，`.md` 文件依旧负责内容本身。即使以后停用插件，你的笔记仍然完整可读。

**一份文件，三种读法。** `.mtn.md` 的可读部分是标准无序列表大纲；AI 工具读到明确提示后无需继续解析压缩区；插件自身则用文件末尾的 gzip + Base64 数据块作为权威数据源。保存时由机器数据重新生成大纲，两者不会各说各话。

**引用要稳，重命名不慌。** 关联文件依靠稳定资源 ID，而不是易碎的路径字符串；重命名或移动文件后引用能够被修复。节点标题与文件名默认双向同步——改标题就是改文件名。

**离线优先，数据自有。** 不发送遥测，不上传库内容，不依赖任何第三方服务。网页链接只保存标题、地址和可选图标，绝不在后台抓取正文。

**只做好有序树。** 首个版本刻意不做自由画布、流程图和任意图结构，也不做多人协作与服务端同步——同步交给你已经在用的方案。

## 安装

**环境要求**：Obsidian **1.8.7** 或更高版本。

### 手动安装（推荐）

1. 打开 [Releases](https://github.com/71-MengYi/obsidian-mind-tree-natrue/releases/latest) 页面，从最新版本的 **Assets** 中下载三个文件：
   - `main.js`
   - `manifest.json`
   - `styles.css`

   > 注意：不要下载 `Source code (zip)` / `Source code (tar.gz)`，那不是插件本体。

2. 在你的库中创建目录 `<vault>/.obsidian/plugins/mind-tree-nature/`。目录名必须与插件 ID 一致，即 `mind-tree-nature`。`.obsidian` 是隐藏目录，需要先开启显示隐藏文件。
3. 把刚下载的三个文件放进该目录，三者必须同级。
4. 重启 Obsidian，或在「设置 → 第三方插件」中点击刷新按钮重新加载插件列表。
5. 关闭**受限模式**，在第三方插件列表中找到并启用 **Mind Tree Nature**。

**移动端**：把三个文件放进库内同一路径即可，可借助系统文件管理器或你正在使用的同步方案。

### 通过 BRAT 安装

已安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 时，可以直接添加本仓库，由 BRAT 负责安装与后续更新：

```
71-MengYi/obsidian-mind-tree-natrue
```

### 更新

插件内置更新器，位于「设置 → Mind Tree Nature → 基础设置 → 插件更新」：可以手动检查，也可以开启启动时自动检查。

更新流程只替换 `main.js`、`manifest.json`、`styles.css` 三个程序文件，并在替换前做大小与 SHA-256 校验；**不会改动你的笔记和 `data.json`**。校验不通过时不会有任何文件被替换。

## 快速上手

### 1. 新建一棵思维树

命令面板（`Ctrl/Cmd + P`）运行 **Mind Tree Nature: 新建思维树**，填写标题与保存目录。

文件以 `.mtn.md` 扩展名保存，之后**打开这个文件就会自动进入导图视图**——插件有意不提供打开其 Markdown 源码的操作，因为大纲只是机器数据的投影。

新建或打开导图的第一个画面，会以 100% 缩放把根节点精确居中并选中，不需要你手动寻找位置。

### 2. 长节点

选中节点后直接按键，不用去找按钮：

| 按键 | 作用 |
| --- | --- |
| `Enter` | 在下方添加同级节点 |
| `Shift + Enter` | 在上方添加同级节点 |
| `Tab` | 添加子节点 |
| `Shift + Tab` | 插入父节点 |
| `空格` | 编辑节点标题 |
| `↑` `↓` | 在兄弟节点间移动 |
| `←` `→` | 在父节点与第一个子节点间移动 |
| `Delete` / `Backspace` | 删除所选分支 |
| `Ctrl/Cmd + ↑` / `↓` | 在同级中上移 / 下移 |
| `Ctrl/Cmd + C` / `X` / `V` | 复制 / 剪切 / 粘贴分支 |
| `Ctrl/Cmd + A` | 选择所有可见节点 |
| `Ctrl/Cmd + Z` / `Ctrl/Cmd + Shift + Z` | 撤销 / 重做 |
| `Ctrl/Cmd + E` | 为当前节点创建 Markdown 笔记并关联 |
| `Ctrl/Cmd + S` | 立即保存并更新 Markdown 大纲 |
| `Ctrl/Cmd + F` | 打开右侧搜索窗口 |
| `Escape` | 取消编辑或拖拽 |

macOS 上把 `Ctrl` 换成 `Cmd`。视图左上角的圆形问号按钮内有同一份完整列表。

`Ctrl/Cmd + F` 或工具栏的**搜索**按钮在视图右侧打开搜索窗口：窗口常驻、失焦不关闭，用右上角 `×` 或 `Esc` 关闭；输入框右侧实时显示命中数量，下方卡片逐条列出命中的节点名、文件名与已关联 Markdown 文件的正文（思维树 `.mtn.md` 不解析正文，为控制开销每次搜索对文件正文有数量与体积上限）。同一卡片的多段命中用分割线分隔，每段单行显示、首尾截断处省略并高亮关键字；点击卡片标题跳到节点并聚焦节点中心，点击内容行直接打开文件并把光标定位到对应行。

### 3. 把笔记挂到树上

- `Ctrl/Cmd + E`：为未关联的节点创建一篇 Markdown 笔记并自动关联。新笔记的打开位置可在设置中选择右侧拆分、新标签页、当前标签页或新窗口。
- 节点右键菜单 →**关联已有文件**：检索库内除当前思维树自身外的全部文件。
- **文件收集**：视图左上角菜单里的「文件收集」决定如何处理思维树旁尚未关联的文件，可选「关闭 / 每次询问 / 添加到一级末尾 / 添加到收集节点」；左下角状态栏的扫描按钮可随时手动扫描当前文件夹中的新增文件。
- **主题预览**：在视图左上角菜单里打开「主题」，把鼠标停在某个主题选项上，选项旁会弹出一个小预览窗口，用示例节点实时显示该主题的配色与连线效果；移到其他选项立即切换，移开就消失。
- 也可以直接把文件从库中或系统里**拖进画布**，剪贴板图片同样支持。

关联之后，节点标题与文件名默认双向同步；不需要同步时，在右键菜单第一项取消**名称关联**即可。解除关联（而不是取消名称同步）后，创建 / 关联入口才会重新出现。

### 4. 导入与导出

未选中节点时，工具栏的**节点标记、关联节点、复制、导出**按钮会禁用；选中节点后恢复可用。

- **节点标记**：工具栏或节点右键菜单打开同一个标记面板，内置「进度 / 优先级 / 高亮」三组（每组最多选一个值，类别删除按钮只清除自己）。面板还会显示你在「设置 → Mind Tree Nature → 管理标记」里添加的自定义 **Emoji** 和**文字标记**两组；点击未选中的项即选中并替换该组原值，再点一次即取消。节点尾部按「自定义 Emoji → 文字标记 / 文件徽标」的顺序显示，文字标记的样式与文件类型标签一致。
- **关联节点**（工具栏「节点标记」右侧，或节点右键菜单「标记」下方）：把当前节点**单向**关联到同一棵树里的另一个节点，选择窗口按「根 → … → 节点名」路径搜索。关联后发起方节点尾部出现一个可点击的链接标志，点击即展开目标所在的折叠分支、选中并把画布居中到目标节点。关联不复制、不移动、不同步任何节点：双方的子节点都保持原样。**节点关联与文件资源互斥**：已关联笔记或其他资源的节点不能建立节点关联（提示「该节点已存在笔记，无法关联」），已被节点关联的节点也不再显示打开按钮、不再提供「添加笔记 / 关联已有文件」等入口——链接标志就占用节点尾部唯一的关联位置。当前节点已参与关联（作为发起方或被关联方）时，菜单与工具栏入口变为**取消关联节点**，点击解除它参与的全部关联，子节点依旧不被改动。参与关联的节点会在大纲行尾带上块 id，并在大纲末尾的链接域里以 `源id->目标id` 单向标注。
- 工具栏**导入文本**：粘贴列表 / 缩进文本还原层级，也可切换到兼容嵌套列表的「多级标题」规则；统一识别 Wiki 链接、Markdown 笔记 / 附件链接和 HTTP/HTTPS URL，每行单链接保留别名，多个链接按顺序拆为独立节点。
- **复制**（工具栏按钮或节点右键菜单）：`复制分支` 直接复制整个分支（粘贴回导图可高保真还原，纯文本则是 Markdown 无序列表）；`复制为…` 展开后有三个选项——**复制分支引用**、**复制为大纲**、**复制为 mermaid 代码**。节点右键菜单里的「复制为…」和工具栏的复制下拉菜单是同一份菜单。
- **导出**（工具栏按钮或节点右键菜单的「导出」展开子菜单）：`导出 PNG` 把分支存成 PNG 图片，`导出 Markdown` 把分支存成 Markdown 无序列表文件，文件名默认取节点标题。
- **复制为 mermaid 代码**：复制一个 ` ```mermaid ` 代码块，内容是 `mindmap` 缩进大纲（层级与分支结构一一对应，节点文本为标题纯文本）。粘贴到任意 Markdown 笔记即可直接渲染成思维导图；Mermaid 没有对应表达的资源链接、节点标记与节点 id 不会导出。子菜单在宿主不支持嵌套菜单时会平铺展开，命令仍然全部可用。
- **复制分支引用**（节点右键菜单「复制为…」第一项）：复制一段 `mind-tree-ref` 代码块，粘贴到任意 Markdown 笔记（阅读模式或实时预览）就会嵌入该节点及其全部后代的**只读**思维树视图——分支范围、字号层级和分支配色都与它在原树中的样子一致。视图里可以平移、缩放和临时折叠（折叠只影响这次显示，不会写回文件）；有关联资源的节点仍可用尾部的灰色打开按钮打开对应笔记，右上角悬浮按钮（鼠标悬浮或键盘聚焦时出现，触摸设备常驻可见）打开原始的思维树视图。除此之外视图不接受任何编辑操作，也不会出现框选、右键菜单或导出入口。

引用绑定「思维树身份 + 节点 id」而不是路径：在树里移动节点、把 `.mtn.md` 改名或移动到别的文件夹都不会让引用失效。第一次复制引用时，如果这棵树还没有身份，插件会自动写入一次 `documentId`（与「首次被其他思维树关联」同一机制）。如果引用的节点被删除或被剪切到另一棵思维树，或者树文件不存在、身份重复、数据损坏，笔记里的视图会改为显示对应提示文字并停止渲染；原树文件仍在时提示旁保留打开按钮。把引用粘贴到导图画布只会提示，不会插入节点。

### 5. 管理自定义标记

「设置 → Mind Tree Nature → 管理标记」只管理你自己添加的标记，不影响内置的进度 / 优先级 / 高亮三组：

- **Emoji**：已添加的 Emoji 以正方形图标按网格排列。下方是一个**搜索框 + Emoji 列表**：搜索框左侧是放大镜图标，列表可上下滚动；不输入时列出**全部**内置 Emoji（约 1300 个，不做截断，滚动即可找到任何一个），输入时实时筛选（支持英文名称和中英文关键词，如 `smile`、`中国`、`flag china`，也可以直接粘贴一个 Emoji 找它本身）。点击列表中的 Emoji 即可添加，已添加的会置灰，因此**每一项必然是单个 Emoji**（👨‍👩‍👧‍👦 这类组合、肤色、旗帜、键帽都算一个），不存在输入文字的路径——文字请添加到文字标记。鼠标悬浮（或键盘聚焦）已添加的图标时右上角出现小删除按钮，点击即删除；按住图标拖动即可调整顺序，落点位置及之后的图标整体往后推。没有添加时网格不占用界面空间，最多 64 个。全部 Emoji 都内置在插件里，检索不需要联网。
- **文字标记**：管理方式与 Emoji 完全相同，只是显示为「绘图」「思维树」那样的文字标签，最多 64 个，每个不超过 24 个字符。文字标记会以同样的标签样式显示在节点标题后方。
- 键盘可用 `Alt + ←/→` 把焦点所在的项左移或右移一位。删除某个标记后，已使用它的节点会立即停止显示该标记，但节点里的引用会保留——重新添加同名标记即可恢复。
- 这些设置只影响显示，立即刷新已打开的导图，不会修改任何 `.mtn.md` 文件，也不会产生撤销记录。
- 与内置标记一样，节点实际选中的自定义标记会作为可读后缀同步到 Markdown 大纲，例如 `- 节点标题 〔emoji:🔥〕 〔tag:绘图〕`，因此大纲始终能说明节点带了哪些标记。

### 6. 让 AI 通过 MCP 读写思维树

插件在桌面端提供**两个本机 MCP 服务器**，Claude Desktop、Cursor 等 MCP 客户端可以按节点 id 直接读写你的思维树。

**为什么是两个服务器**：MCP 客户端把「工具是否需要你确认」的审批策略挂在**服务器**上，而不是单个工具上。所以想让 AI 免审批地读取、同时又要求写入必须确认，唯一可行的做法就是把两者做成两个服务器。插件本身不再按工具拦截任何调用——分不分权，由你在客户端里逐服务器决定。

1. 打开「设置 → Mind Tree Nature → **AI**」（该页只在桌面端出现）。
2. 打开**开启 MCP 服务**。两个服务器都只监听本机 `127.0.0.1`；端口被占用时会自动尝试附近的端口，状态行显示实际生效的地址。
3. 点击**复制配置 JSON**，把它粘贴进客户端的 MCP 配置文件（Claude Desktop 的 `claude_desktop_config.json`，或 Cursor 的 `mcp.json`）。配置里已经包含两个服务器的地址和各自的访问令牌，不需要手工补字段。
4. 在客户端里给两个条目设置不同的审批策略：**只读服务器**设为免审批，**写入服务器**设为每次确认。这正是拆成两个服务器的意义。
5. 如果暂时不需要让 AI 改动任何东西，就不要打开**开启写入服务器**（默认关闭），这样配置里只会出现只读那一条。

| | 只读服务器（`mind-tree-nature-read`） | 写入服务器（`mind-tree-nature-write`） |
| --- | --- | --- |
| 默认端口 | `27321` | `27322` |
| 默认状态 | 随总开关开启 | **关闭**，需要单独打开 |
| 包含的工具 | 列出思维树、读取整棵树（可切换扁平/嵌套形态并按节点数分页）、按标题查找节点、读取某个节点及其父节点/子节点（可选递归整棵子树）/标题路径/关联文件与节点关联、读取节点数/文件数/深度 | 把节点移动到另一个节点下、在指定节点下新增子节点、重命名节点、删除单个节点（子节点上提）、关联或取消关联文件、建立或取消同文档内的节点关联、**新建整棵思维树** |
| 能否改动文件 | **不能**。这里没有任何会写入的工具 | 能，全部改动都在这里 |

几条刻意设定的规则：

- 每次修改都和你在界面上操作一样，是**一步可撤销**的普通编辑，并会立刻保存到文件。
- **只读服务器里不存在任何写工具**，所以它无法改动你的仓库，可以放心免审批运行。写入服务器里也不存在读工具——两个服务器的工具清单完全不重叠。
- 两个服务器使用**不同的端口和不同的访问令牌**，因此只读那条配置无法获得写入权限。
- 升级到本版本后，**写入服务器一律默认关闭**，需要你手动打开；插件不会因为你以前开过写权限就自动放开。
- **取消关联只是删掉节点上的引用，绝不会删除你的文件**；关联也只接受仓库里已经存在的文件，不会新建、导入或移动文件（还没有资源身份的非 Markdown 文件，会像你在界面上关联一样在同一个文件夹里补上身份后缀）。
- MCP 不能删除整枝，也不能删除文件。
- 文档存在未决的外部改动、或文件在操作期间被别的程序改写时，写入会被拒绝并说明原因，**此时任何文件都不会被覆盖**。
- 通过 MCP 新建思维树不会抢走你当前打开的视图。
- 移动端不显示这一页、也不会启动服务；即使把桌面端已开启 MCP 的配置同步到手机，手机依然不会启动。

访问令牌保存在**设备本地存储**而不是插件数据里，因此不会被同步到其他设备。它等价于密码：任何能读到它的人都能修改你的思维树，请像对待密码一样对待复制出去的内容。

## 文档格式与隐私

- 思维树使用顶层 YAML 属性 `documentId`、`schemaVersion`、`layoutMode`、`recursiveScan`、`collectionMode`、`theme` 和 `nodeShape`，其后是一段 Markdown 大纲。大纲之后存放无损 gzip 压缩的 JSON，并附有一条明确要求 AI 工具忽略它的说明；设置项不会在该载荷中重复保存。新建思维树不写入任何设置属性，缺失的设置在运行时使用「设置 → 思维导图」中的全局默认值，只有在该树左上角设置菜单里主动选择某项后才写入该文件并固定下来。
- 插件不发送遥测数据，也不上传库内容。
- 插件唯一的网络相关功能是本机 MCP 服务：它默认关闭、只在桌面端、只监听 `127.0.0.1`、需要访问令牌，并且不向任何服务器发送数据。除此之外只在你主动点击检查更新时访问 GitHub。
- 网页链接只做存储，绝不在后台抓取。
- 所有界面文案由 i18n 提供简体中文与英语两套资源，并跟随 Obsidian 界面语言。

产品与技术基线见[设计文档](docs/requirements.md)。
