## 全局交互与格式约束

1. 在画布空白区域按住左键拖拽执行框选；按住右键拖拽移动画布。节点上的右键单击仍打开节点菜单。
2. 节点宽度由当前 Obsidian 字体的实际标题测量宽度、上下各 `3px` 与左右各 `5px` 的内边距及尾部元素实际宽度共同决定，不设置固定最小宽度；图片主体采用同一外边距。只有根节点保留 `32px` 最小高度；一级及更深节点按实际文字行高和内部元素高度确定。所有节点无实体边框。
3. 插件不提供“打开思维树源文件”的按钮、菜单项或命令。用户通过导图视图使用 `.mtn.md`，无需访问源文件。
4. `.mtn.md` 用扩展名、有效的顶层 `schemaVersion` 和压缩数据区识别文档；`documentId` 是首次被另一棵树关联时才生成的可选 UUID，不是识别前提。`layoutMode`、`recursiveScan`、`collectionMode`、`theme`、`connectionStyle`、`nodeShape` 各自保存为顶层属性，不使用设置字典，也不在 Frontmatter 保存压缩 JSON。完整机器数据在无序列表大纲之后，以分割线和“这段话之后的内容是压缩json，无需读取和分析。”提示分隔，再写入 gzip + Base64 数据块。当前无版本号格式定义为最早兼容的 v1；只有影响导图识别或核心机器数据解码的结构变化才提升版本并进入统一迁移工厂。任何树设置在文件中缺失时，只在运行时使用对应全局默认值，不因此标记待保存或重新写入属性；新建导图同样不写入任何设置属性，只有用户在树菜单主动设置某项时才写入该字段。不为普通设置增加迁移版本，也不得在业务代码中散落兼容分支。
5. 文件节点默认让节点名与文件名双向关联；可在节点右键菜单第一项取消名称关联。节点内部不显示左侧类型图标，文件节点最右侧显示 `fa-share-square-o` 打开按钮，打开位置由设置决定。
6. `Ctrl/Cmd+E` 只为未关联节点创建 Markdown 笔记；已关联节点显示提示。普通新笔记正文使用全局“新笔记默认填充内容”，不根据节点名自动生成一级标题。“从模板添加文件”支持模板目录及子目录内的全部仓库文件，只复制所选文件并替换副本关联身份，不处理内部引用、模板变量或默认笔记内容。两者沿用相同保存目录和新文件打开位置设置，可在右侧拆分、新标签页、当前标签页或新窗口打开。
7. 所有用户界面文案通过 i18n 提供简体中文和英语两套资源，并跟随 Obsidian 界面语言。
8. 每个导图视图左上角提供竖向圆角菜单栏：树设置按钮只放置布局、主题、连线样式、节点形状、文件收集策略与“扫描子目录”，圆形问号按钮显示完整快捷键表。全局布局、主题、连线样式、节点形状和文件收集策略是尚未单独设置该项的导图（含新建导图）的运行时默认值，不写入文件；主题笔记、删除/导出、扫描忽略规则，以及其余外观和节点对齐偏好保留在插件全局设置页。文件收集策略可选关闭、每次询问、添加到一级末尾、添加到收集节点。十套主题按根节点一级分支的当前顺序循环使用十二色，前十二个分支颜色不重复且每个分支的后代继承该分支颜色；主题分别定义连线路径、虚实、端点、透明度和阴影，所有连线的实际描边宽度统一为 `1px`。
9. 左下角状态栏显示主题数、按稳定资源 ID 去重的关联文件数和树深度，依次提供根节点 100% 复位、红绿保存状态和手动扫描当前文件夹新增文件的按钮，以及位于圆角矩形外部的独立撤销、重做按钮；文件数包含全部仓库文件引用但不包含 URL，顶部工具栏不重复显示撤销、重做。
10. 未关联节点可通过“关联已有文件”检索除当前思维树自身外的全部仓库文件。关联文件或 URL 后，创建/关联入口全部隐藏，必须先“移除关联”才能重新关联；“取消关联”仍只关闭文件名同步。桌面端在“打开资源”下方增加“使用默认应用打开”，文件使用系统默认应用、URL 使用默认浏览器；移动端隐藏新项，原有打开行为不变。节点右键菜单在删除板块下方提供“将关联文件移动到”，可搜索仓库文件夹、快速填入当前导图文件夹，并选择只移动当前节点的文件或移动当前分支的全部关联文件；URL 不参与移动。
11. 新建和打开导图的首个可见画面始终以 100% 缩放将根节点精确居中并选中，不显示通用“思维树视图”切换通知；方向键支持兄弟与父子节点导航，新建节点的编辑焦点继续使用普通选中的虚线外框，不放大节点。
12. 多选节点后，按住任意已选节点拖拽会移动全部选中分支。选中集合同时包含祖先与后代时只移动最上层分支并保留内部连接；来自不同子树且未连同父节点选中的分支，在目标落点统一成为同级兄弟节点。拖拽预览仍只显示鼠标按住的一个节点。
13. 节点标题保持左对齐；标题区域与尾部区域独立测量，标记、资源徽标和资源按钮只能从标题区域右侧增加节点宽度，不得移动标题左侧锚点。纯文本节点不得为隐藏控件预留尾部空间。
14. 顶部文本导入窗口默认选择“列表 / 缩进文本”，也可切换到兼容标题间嵌套列表的“多级标题”规则建立节点层级。导入与外部单行直接粘贴统一识别 Wiki、Markdown 笔记/附件链接和 HTTP/HTTPS URL；每行单链接保留别名或说明，多个链接按出现顺序拆为独立关联的兄弟节点，链接外说明单独作为第一节点，后续子项归第一节点。文件标题遵循全局同步设置；未找到文件时保留原始链接并提示。多行文本转入预填导入窗口，插件内部结构化分支粘贴保持不变；每批解析与关联完成后只提交一次撤销记录。所有文件和网页关联节点使用相同的灰色打开图标，只有文件支持同步关闭标志。活动导图必须能在首次粘贴事件缺少纯文本时通过系统剪贴板完成同一次操作，且不得拦截可见输入控件的原生粘贴。新关联的非 Markdown 文件使用 5 位大小写字母数字 ID，并按“主题笔记 → 笔记关联”中的 `@`/`%` 分隔符设置写入文件名；设置只影响新文件，历史 `~mtn-<10 位 ID>` 继续解析且不自动改名。
15. 仅外部压缩 JSON 的逻辑数据变化时，在原标签内显示双栏只读预览，由用户选择节点版本；普通 YAML 属性按最新值接收，删除后保持缺失。已有 documentId 删除或替换时提供独立的身份恢复与重新检查入口，不混同为不可操作的版本选择。未决本地版本在插件目录按本机暂存，关闭或重启后继续处理；不再创建或扫描旧 Recovery 文件，既有文件保持不动。同一路径复用已有导图标签。
16. 所有文字型资源标签使用 `10px/600` 字体、`12px` 行高与四周各 `2px` 内边距，按实际文字宽度收缩。非 Markdown 文件可显示由文件名完整后缀派生的中性灰扩展名标签；全局“基础设置”可按完整后缀或末级扩展名忽略标签或设置别名，忽略优先于别名。扩展名标签只属于运行时视觉，不进入节点 JSON 或 Markdown 大纲。
17. 图片文件以“图片主体 + 底部信息行”的节点直接显示，可从仓库/系统拖拽、关联已有文件或剪贴板添加。新图片按原比例适配在 `180×135px` 内且不放大小图；右下角低强调手柄允许在 `60–600px` 宽度内锁定比例缩放，每个引用的显示宽高只进入压缩 JSON。图片继续作为仓库实体文件管理，PNG 与内部 SVG 导出嵌入安全图片数据，加载或导出失败时降级为普通关联文件节点。

18. 节点标题保存 Markdown 源码，非编辑态显示行内公式、代码、加粗、斜体、删除线及高亮；画布、预览和图片导出共用排版。根节点允许普通格式但禁止公式和代码，文件名采用去格式文字；已开启文件名同步的关联节点禁止提交格式。创建笔记和重新开启同步时普通格式转为纯文字，公式或代码阻止操作。提交失败保留输入与编辑状态；主动关闭或退出丢弃未提交输入。复制及 Markdown 大纲保留支持的格式语法，不增加文档字段或设置。

19. 标记工具在内置“进度 / 优先级 / 高亮”三组之外提供用户自定义的 Emoji 与文字标记两组；自定义定义属于插件全局设置（`data.json` 的 `customMarkers`），只保存稳定 id、类型与值，节点只保存 `{ type: "emoji" | "tag", value }`，不复制定义、不写入 `.mtn.md` 的 YAML，也不进入 Frontmatter。Emoji 与文字标记是两个互相独立的类别，各自最多选择一个值，与三个内置类别互不影响。设置页“管理标记”tab 按“Emoji 标题 → Emoji 网格 → 输入框与添加按钮 → 文字标记标题 → 文字标记网格 → 输入框与添加按钮”的顺序排列；网格中的项是可拖拽排序的方框，鼠标悬浮时右上角出现删除按钮，拖动时目标位置及其后的项往后推；某一组为空时该网格不占用界面空间。在设置中删除某个自定义标记后，已引用它的节点保留该值但立即停止显示，重新添加同值即可恢复；新增、删除与排序都是纯显示设置，立即刷新已打开的导图，不产生文档修改、撤销记录或文档脏状态。
