# 06 测试、验收与里程碑

> 定义测试策略、P0 验收标准和实施里程碑。

## 13. 测试策略

### 13.1 单元测试

- 树新增、删除、迁移、排序、循环检测与撤销/重做。
- `.mtn.md` 扩展名、顶层 `schemaVersion` 与压缩数据区识别，可选 `documentId` 的条件序列化、JSON 稳定序列化、gzip/Base64 编解码、结构校验与未知字段保留；文件不得在 Frontmatter 中保存机器数据，压缩 JSON 不得重复保存版本或文档 ID。
- 统一迁移工厂对影响文档识别/解码的相邻结构版本进行逐级迁移、缺失中间迁移、过旧/未来版本拒绝、迁移后校验及失败时不覆盖原文件；普通设置缺失不进入工厂。
- 当前或未来树设置缺失时仅在运行时使用默认值；保存、重开和节点撤销不补回。主动设置（含选择当前默认值）可重新写入，撤销该设置可恢复缺失状态。
- Markdown 大纲的转义、确定性生成，以及手动修改不影响机器数据。
- 路径规范化、Frontmatter/文件名 ID 提取、重命名、重复 ID 和候选冲突。
- 文件名清理、默认双向同步、逐节点取消/恢复同步、5 位大小写字母数字 ID、`@`/`%` 分隔符、历史 `~mtn-` 后缀兼容保留和 URL 协议校验。
- 混合有序/无序/缩进文本及多级标题（含正文、跳级和标题间嵌套列表）解析；统一识别 Wiki、Markdown 文件和 HTTP/HTTPS 链接。覆盖单链接标题提取、多链接及重复链接的顺序拆分、说明节点和子层级归属、缺失文件保留原始链接、全局标题同步、身份冲突与异步切换取消；展开后的节点数/深度继续受安全上限约束。导入窗口默认选中列表规则。
- 深度到节点文字尺寸的映射：根节点保留 `32px` 最小高度，一级与二级及以后按实际文字行高和内部元素高度决定；所有层级宽度均由实际字体测量和尾部元素实际宽度决定。
- 图片默认尺寸适配、原比例缩放边界、图片样式运行时校验、剪贴板图片优先级和安全导出数据嵌入。
- 模板目录递归展示所有文件；保留末级扩展名/完整 `.mtn.md`/无扩展名、重名保护和并发路径预留。Markdown 副本只替换资源身份，思维树压缩区及内部引用不变，二进制副本逐字节相同，新旧 ID 模板多次复制后身份均独立。
- 模板目标会话切换、节点删除或新增关联时安全中止；复制、身份写入及注册失败只回收新副本并清理索引，回收失败显示路径；已接受副本及同路径替换文件不得被误删。
- 未关联、笔记、图片、附件、思维树和 URL 的资源菜单顺序正确；所有已关联节点隐藏创建/关联入口，关闭标题同步仍不能替换资源，移除引用后才能重新关联。桌面端“使用默认应用打开”紧随“打开资源”，移动端隐藏。
- 共享关联目标校验覆盖旧弹窗、切换文件、节点删除、另一视图抢先关联及领域草稿再次检查；拒绝操作不修改标题、资源或撤销历史。旧菜单比较稳定身份，重命名仍有效，资源替换后失效。
- 默认应用打开通过模拟系统接口验证全部文件类型、最新规范路径、空格/中文/系统路径分隔符、HTTP/HTTPS、危险协议拒绝、文件缺失、不支持适配器、系统异常及非空错误返回；移动端不加载 Electron，打开本身不修改文档或视口。

### 13.2 集成测试

- 创建导图、保存、重载后结构和资源引用一致。
- 保存后的新建且未关联 `.mtn.md` 不含 `documentId`；首次被另一棵树关联后才写顶层 UUID，且后续保存保留它。文件头只使用整数 `schemaVersion`，不含压缩 JSON；无序列表之后依次出现分割线、指定 AI 忽略提示和 `mtn-data-gzip` 数据块，且无 `format`、`version` 或 `revision` 等并行版本字段。
- 打开最早兼容的 v1 文件会通过统一工厂自动迁移并标记待保存；保存后得到当前版本，文档结构与资源关联不变。
- 新建/关联/移动/重命名笔记后 Obsidian 事件与导图状态一致。
- 创建、修改及重复元数据通知交错时，Ctrl/Cmd+E 只创建一个文件并关联一次；三轮内的读取竞态可恢复，真实 ID 变化、同路径替换和重复 ID 仍阻止错误关联。创建成功后的失败保留文件并报告完整路径。
- 批量收集立即显示独立于保存状态的中性进度，结束后一次提交、一次重绘、一次撤销；覆盖部分失败、重复收集、处理期间已有资源关联、切换文件、关闭和冲突取消。固定 1,000 个已有文件与 30 个新文件的基准记录耗时及读取/清单检查次数，不得逐目标全库扫描。
- 四种文件收集策略分别关闭扫描、每次询问、自动加入一级末尾或自动加入“收集”节点，且不会重复加入已关联文件。
- 外部修改文件名/自动标题、大纲、正文或未知 Frontmatter 时不误报，gzip/Base64 表达变化不误报；最新正文和未知 YAML 保存后仍在。只有机器 JSON 数据变化需要双栏版本选择，干净会话同样如此；六项树设置按最新属性接收。误删 documentId 可通过独立入口恢复原身份，恢复不得覆盖节点；重复 ID、未来格式及损坏数据仍禁止覆盖。
- 所有入口及并发打开、工作区恢复按路径复用原导图标签，包含分栏、弹出窗口和冲突预览；不同文档不能被误关。共享会话仍保证唯一文档、历史、写入队列和冲突状态，关闭未决标签不自动选择。
- 标题草稿在普通关闭、保存及身份写入前提交；进入预览则先冻结并暂存，不触发文件改名，选择当前版本才恢复副作用。连续外部更新、点击时又变化、写后同步替换均不接受未展示版本。暂存失败禁止选择，重启恢复，回执及清理失败可重试；旧 Recovery 文件不再扫描或新建。
- 跨导图复制粘贴后结构、资源关联、标记和原始标题一致且节点 UUID 不重复，内部结构化节点不得被重新解析或拆分；Obsidian 内外复制的文字首次粘贴即可处理，即使事件未提供纯文本也能从系统剪贴板兜底。外部单行文字与两种导入共用 Wiki/Markdown/URL 解析及多链接拆分，整批仅产生一次撤销记录；多行文本打开预填导入窗口并默认选择列表规则，仍可手动切换为多级标题规则。重复附件在首次 ID 分配改名后仍全部关联正确。
- 仓库拖拽、系统拖拽、文件选择和单图/多图剪贴板粘贴都生成稳定的图片文件引用；部分失败可报告并清理未提交文件，结构化图片节点复制后保留独立显示尺寸。
- 从模板创建 Markdown、图片、PDF、压缩包、Canvas、Excalidraw、思维树及无扩展名文件，确认源模板不修改、不复制内部链接指向的资源；实际类型/徽标、标题同步、目的目录和四种自动打开位置正确。打开失败保留已关联文件，普通新建笔记不受影响。
- 普通笔记在异步创建期间目标失效时保留新文件并显示路径；已有文件关联失败不删除文件，模板副本仍按已实现的回收规则处理。关联网页的旧弹窗不能覆盖另一窗口已提交的文件或 URL。
- Windows、macOS、Linux 路径差异及移动端降级行为。
- 插件的工具栏、菜单、命令面板和命令注册表均不存在打开导图源文件的入口。

### 13.3 视觉与手工测试

- 在桌面 Obsidian 检查系统默认应用及默认浏览器实际唤起，原“打开资源”和尾部图标保持既有打开位置；在移动端检查不显示新项且原菜单、触控和插件启动正常。
- 浅色/深色主题、20%–300% 缩放、不同 DPI 和窄屏布局；连续放大、缩小、平移、编辑及恢复 100% 后节点文字必须保持一致清晰，不能持续显示低分辨率缩放纹理或新旧栅格混杂；普通节点悬停时保持静态。
- 五种布局切换后的方向、根节点位置、节点无重叠和连接锚点；均衡布局按子树高度右侧优先分配，放射布局从右侧顺时针覆盖多个象限；根分支 45 px、普通层 32 px、同级子树至少 9 px，节点矩形和首尾外延区的拖拽命中符合布局方向。
- 十套无渐变主题的浅色/深色对比度、按一级分支当前顺序循环且由后代继承的十二色映射、主题专属路径/虚实/端点/透明度/阴影、全布局与深度统一的 `1px` 描边、五种手动连线覆盖及三种按树保存的节点形状；多选拖拽仍只显示一个浮层，画布和 PNG 输出一致。
- 从画布空白区域左键拖动显示框选框，并实时显示相交节点的选中效果；从节点开始左键拖动只移动节点。
- 右键拖动画布平移且松开后不弹菜单；右键单击节点正常打开节点菜单。
- `Ctrl/Cmd` 点击切换多选，不破坏左键框选结果。
- 多选任意深度、不同父节点的分支后，按住任意已选节点可整体拖入目标；祖先与后代同时选中时只移动祖先一次，失去原共同父级的顶层分支按树顺序成为目标下的同级节点，并可一次撤销。
- 新建、前台打开和后台标签页首次显示时，首个可见画面均为 100% 缩放且根节点中心精确对齐画布中心；定位前不闪现默认或上一文件视口，也不弹出通用“思维树视图”通知。
- `↑`/`↓` 按结构顺序遍历兄弟节点；`←`/`→` 按向右、向左、树形、均衡和放射布局的可见方向在父节点与第一个子节点间导航，且不进入折叠分支。
- 根、一级、二级及更深节点使用三档尺寸，深度二及以后完全一致；PNG 导出保持相同层级规则。
- 长标题、Emoji、中日韩文字、RTL 文本和非法文件名字符。
- 1,000 节点导图、深层嵌套和大量图片引用。
- PNG 与内部 SVG 中图片数据正确嵌入且不泄露仓库临时地址；SVG 源图安全栅格化，损坏、丢失或超限图片按普通文件节点降级。
- 图片节点在五种布局下保持“图片主体 + 紧凑底部信息行”，右下角手柄只在悬停或选中时显示；`60–600px` 按比例缩放期间连线同步且画布不复位，松开只产生一次撤销，取消则恢复。
- 键盘全流程、焦点顺序和屏幕阅读器标签。

## 14. P0 验收标准

满足以下条件才视为首个可用版本完成：

1. 能创建只包含一个根节点的 `.mtn.md`，在自定义视图中编辑，并在重新打开后无损恢复节点顺序、层级和资源引用。
2. YAML Frontmatter 以唯一整数 `schemaVersion` 驱动关键结构迁移，并将 `layoutMode`、`recursiveScan`、`collectionMode`、`theme`、`connectionStyle`、`nodeShape` 分别保存为同级属性，不使用设置字典且不保存机器数据；`.mtn.md` 扩展名、有效版本与压缩数据共同识别导图。`documentId` 是首次被另一棵树关联时才生成的可选 UUID，缺失不影响 v2 打开。全局默认布局、文件收集策略、主题、连线样式与节点形状只初始化新建导图或回填旧文件缺失属性。文件中存在可读 Markdown 无序列表，并在其后用分割线和“这段话之后的内容是压缩json，无需读取和分析。”明确隔开 gzip + Base64 压缩 JSON。压缩 JSON 不重复保存 `documentId`、版本或设置，文件不写 `format`、`version`、`revision` 等并行版本字段。最早兼容 v1；只有影响导图识别或核心数据解码的结构变化才提升版本并通过统一工厂逐级迁移，普通设置缺失不提升版本。大纲仅由机器数据生成，手动修改不会进入画布，普通 Markdown 说明不会被插件删除。
3. 支持从画布空白区域左键框选、`Ctrl/Cmd` 切换多选、右键平移画布、新增子节点/兄弟节点、标题编辑、拖拽三类落点、两种删除语义、折叠、撤销和重做；左键从节点开始拖动不触发框选，右键拖动结束不误触菜单。按住任意已选节点拖拽会整体移动全部选中分支；跨层级选择保留已选祖先内部关系，其余顶层分支在目标位置成为同级节点。
4. 节点使用三档字号和行高，只有根节点保留固定最小高度且所有层级均不设固定最小宽度；标题区域保持独立左侧锚点，标记、资源徽标和文件控件只向屏幕右侧增加完整节点宽度。文字资源标签以四周 `2px` 内边距按实际文字宽高收缩；扩展名标签支持全局忽略和别名规则，包含 `md`、`plugin.md` 等 Markdown 后缀，Markdown 仅在匹配别名时显示，专用思维树／绘图标签保持优先。标签只作为画布与导出的派生视觉，设置变更不修改文档或撤销历史。短标题及带尾部元素的节点按实际字体与内容紧凑收缩，画布与 PNG 导出结果一致，节点容器无实体边框。
5. 工具栏、右键菜单和已注册命令中均不提供打开 `.mtn.md` 导图源文件的入口；节点的“打开资源”只打开其关联资源。
6. 新建或关联任何文件后默认同步节点名与文件名；修改节点名可安全重命名文件，取消关联后显示同步关闭标志并停止互相改名。
7. Markdown 资源的 ID 可从 YAML Frontmatter 重建；新关联的非 Markdown 资源使用可配置的 `@` 或 `%` 分隔符加 5 位大小写字母数字 ID，历史 `~mtn-<10 位 ID>` 仍可重建且不自动改名。文件移动、重命名及索引丢失后引用仍可恢复。
8. 每棵树可关闭文件收集，或选择每次询问、自动添加到一级末尾、自动添加到“收集”节点；全局“思维导图”设置只提供新树默认值，各模式均不重复加入已关联文件。
9. 分支可复制到另一份导图，粘贴后层级和资源关联不变且 UUID 不冲突；外部单行文字可直接创建节点，多行文本进入默认选择列表规则的导入窗口。导入支持混合列表/缩进文本及夹有嵌套列表的多级标题，和直接粘贴共用唯一 HTTP/HTTPS URL 关联与标题提取规则；多网址及文件链接不自动关联。文件和 URL 节点共享灰色打开图标、`20px` 按钮及 `2px` 前置间距，URL 不显示同步关闭标志；也可导出为无序列表和 PNG 文件。
10. 文件头版本无效、压缩数据损坏、外部版本变化或磁盘写入失败时，不用空数据覆盖原文件；缺少 `documentId` 的 v2 文件仍可正常打开、编辑和保存。未决版本选择能在关闭/重启后恢复；无法安全定位暂存目标时报告并保留记录，不猜测文件。
11. 核心树操作、格式编解码和索引解析具备自动化测试，性能达到第 9.3 节基线。
12. 核心流程可在桌面端完成；移动端支持单指平移、点选、双击原地编辑、长按菜单/节点拖动、双指连续缩放与图片手柄缩放，不依赖 Node.js 专属 API。真实 iPhone/iPad 需检验画布中央/边缘滑动不触发宿主侧栏和下拉操作，画布外与原生输入不受影响；浏览器模拟不能替代真机验收。
13. 文件节点不显示左侧类型图标，最右侧显示静态、无悬停提示的 `fa-share-square-o`；点击后按设置在新标签页或右侧竖向拆分打开。界面完整支持中文和英语。
14. 视图左上角显示竖向圆角菜单栏：树设置按钮只包含布局、主题、连线样式、节点形状、文件收集策略和“扫描子目录”，圆形问号按钮完整列出实际支持的快捷键。全局“思维导图”设置保留默认布局、默认主题、默认连线样式、默认节点形状、默认文件收集策略，以及同级节点对齐/紧凑布局切换；两种对齐策略下节点均不得重叠。
15. 非编辑状态下 `Enter`/`Shift+Enter` 分别在下方/上方添加同级节点，`Tab` 添加子节点，`Shift+Tab` 插入父节点；编辑状态下这四种按键均只确认并保存标题，下一次独立按键才执行结构创建，长按自动连发不会批量创建。`Ctrl/Cmd+E` 为未关联节点创建 Markdown 笔记并按全局设置打开，已关联时提示，空格从标题末尾开始编辑，`Delete`/`Backspace` 打开删除对话框；文本编辑状态下保留其余输入控件自身行为。
16. 折叠按钮仅在节点选中、节点/按钮悬停或键盘聚焦时显示；标题输入框无边框和圆角、上下间距紧凑，并随原始编辑草稿采用动态宽度与换行高度，前导、尾随和连续空格必须可见且推动光标；确认时裁掉绝对首尾空格并保留内部空格。连续双击不同节点编辑时不会发生标题串写。
17. 删除对话框始终显示警告、可展开的主题/关联文件统计及四个独立操作按钮；默认回车仅删除主题，实际文件删除通过 Obsidian 回收站执行。导图画布无边框并填满视图内容区。
18. 左下角状态栏准确显示主题数、按稳定资源 ID 去重的全部关联文件数和树深度，文件数不包含 URL；状态栏提供根节点 100% 复位、红/绿保存按钮及保存按钮右侧的手动文件夹扫描按钮。手动扫描清除缓存并检查新增文件，在自动收集关闭时改为显示候选列表。撤销、重做位于状态栏圆角矩形右侧且不再出现在顶部工具栏。未关联节点可检索除当前树自身外的任意仓库文件；节点菜单可搜索目标文件夹并移动当前节点文件或分支内全部关联文件，重复引用只移动一次且不覆盖冲突文件。
19. 新建和打开导图时首个可见画面始终在 100% 缩放下将根节点精确置于画布中心并显示普通虚线选框，后台标签页首次显示也不闪动；`↑`/`↓` 可遍历兄弟节点，`←`/`→` 可按布局方向进入第一个子节点或返回父节点。`Tab`/`Enter` 新建并编辑节点时使用相同虚线外框，不放大节点；视图切换不显示“思维树视图”通知。

## 15. 里程碑建议

### M1：格式与领域模型

- 完成唯一根节点树模型、命令系统、顶层 `schemaVersion` 与可选 `documentId` 文件头、大纲单向生成、底部压缩数据区和往返测试。
- 完成统一版本迁移工厂、v1→v2 关键结构迁移、设置缺失默认回填与版本拒绝测试；解析器只接受当前结构或工厂能够逐级迁移的受支持结构，不在其他模块提供迁移分支。
- 用简单列表视图验证数据正确性，不提前投入复杂画布交互。

### M2：基础画布

- 完成自定义视图、节点渲染、编辑、折叠、节点拖拽、左键框选、右键平移、缩放和撤销。
- 完成三级节点尺寸规则，并让画布渲染与 PNG 导出共用深度映射。
- 完成自动保存、外部修改检测和基础恢复。

### M3：Obsidian 文件集成

- 完成文件索引、同目录扫描、新建/关联笔记、重命名同步和失效修复。
- 完成仅含布局、主题、连线样式、节点形状、文件收集策略与递归扫描的视图菜单、三页插件设置界面和关键集成测试，并确认没有导图源文件入口。

### M4：交换与发布准备

- 完成复制粘贴、Markdown/PNG 导出、性能优化、移动端适配和无障碍检查。
- 补齐文件格式拒绝测试、用户文档和发布检查表。


## 设置与本机索引隔离验收

- `data.json` 仅输出用户设置；扫描、关联、移动、重建、卸载不夹带旧设置保存。
- 外部设置更新取消未执行的旧快照及失败重试；读取损坏 JSON 不覆盖原文件；升级清理只移除旧索引并保留最新设置原值。
- 本机缓存损坏、缺失、容量不足可降级重建；同 ID 候选不丢失，历史路径不作为原件证明。
- Markdown、思维树和非 Markdown 的重复 ID 均阻止新关联和文件改写；精确匹配的既有文件只读打开仍可用；首次关联和模板副本生成独立 ID。
- 重建过程中新增、删除、修改、改名及读失败不会发布过期路径；旧路径被新 ID 占用不能继承旧关联。重建不改文件和导图保存状态。
- 自动化覆盖设置 I/O、缓存、真实资源服务边界、模板回归和异步索引；桌面与移动端需使用测试仓库实机核对原生 Sync、重建进度及窗口关闭。
