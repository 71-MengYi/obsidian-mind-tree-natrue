## 5. 信息架构与界面

### 5.1 主视图

主视图由以下区域组成：

1. **左上角竖向圆角菜单栏**：包含当前树设置按钮和圆形快捷键帮助按钮。
2. **顶部居中工具栏**：常用操作和当前视图控制。
3. **导图画布**：节点渲染、选择、拖拽、缩放和平移。
4. **右键菜单**：对当前节点或选中分支执行操作。
5. **左下角状态栏**：显示导图统计、画布复位、保存状态和撤销/重做。
6. **状态提示区**：显示保存失败、冲突和只读错误；无异常时不占用空间。
7. **弹窗/命令面板**：用于文件搜索、模板选择、目录选择、导出和冲突处理。

首个版本不增加常驻侧栏，避免压缩画布。低频属性通过弹窗或右键菜单编辑。

插件不提供“打开思维树源文件”的按钮、菜单项或命令。用户始终从导图视图使用文档，无需访问 `.mtn.md` 源文件。

Ribbon 的“新建思维树”按钮打开一个包含名称和目标文件夹的对话框。文件夹可以搜索并从仓库现有目录中选择，包含仓库根目录；默认选中当前活动文件所在目录。只有名称非空且目标文件夹有效时才允许创建。命令面板的新建命令仍默认创建到当前活动文件所在目录。

### 5.2 左上角设置菜单

竖向圆角菜单栏固定在视图左上角，不随画布缩放或平移。树设置按钮的菜单只包含布局、主题、连线样式、节点形状、文件收集策略和“扫描子目录”：布局、主题、连线样式、节点形状与文件收集策略进入带当前选中标记的二级菜单，“扫描子目录”直接勾选切换。修改后立即重绘或重新扫描，并通过正常撤销与自动保存流程写入当前 `.mtn.md` 的 YAML。

菜单栏中的圆形问号按钮展开完整快捷键及动作说明，内容必须与实际键盘处理保持同步。

全局“思维导图”页中的布局、主题、连线样式、节点形状与文件收集策略分别作为新建思维树的默认值，不覆盖已有思维树；它们也作为缺失属性的运行时回退值，不自动补写 YAML。换行宽度、`Ctrl/Cmd+E` 新笔记打开位置、扫描忽略规则、主题笔记和 PNG 导出倍数仍保留在插件全局设置页。未被明确认定为树级差异的选项不得自行移入该菜单或写入文档 YAML。

### 5.3 顶部工具栏

从左到右建议为：

- 全部展开所选分支；多选时作用于全部顶层选中分支，无有效选择时作用于根节点。
- 递归折叠所选分支；目标节点及其后续分支都会进入折叠状态，以便之后手动逐层展开。
- 按层级折叠；菜单提供 `1～9` 级，根节点记为第 `0` 级，选择第 `N` 级后全树显示到该级并折叠更深分支。
- 节点标记；按钮只显示图标，作用于当前主选节点。
- 适应画布、缩小、缩放比例、放大。
- 搜索。
- **复制**下拉菜单：
  - 复制为 Mind Tree 分支。
  - 复制为 Markdown 无序列表。
  - 复制为 PNG（P1）。
- **导入文本**：打开多行输入窗口，默认选择“列表 / 缩进文本”，也可切换为支持嵌套列表的“多级标题”规则，并将结果添加到所选节点下。
- **导出**下拉菜单：
  - 导出选中分支为 PNG 文件。
  - 导出选中分支为 Markdown 无序列表。

工具栏按钮必须有 tooltip、禁用状态和键盘可访问名称。画布本身通过视觉隐藏文本和 `aria-labelledby` 提供无障碍名称，不得把名称作为覆盖整个画布的悬停提示。窄屏下将低频操作折叠进“更多”菜单。

展开、递归折叠和按层级折叠均只产生一个撤销记录，保持原有节点选择及画布位置，并通过现有自动保存流程持久化节点 `collapsed` 状态。顶部不再放置添加子节点按钮；Tab、命令面板和节点右键菜单仍可添加子节点。层级菜单不是树设置，不新增 YAML 属性。

布局通过视图左上角设置菜单或命令面板切换，只影响当前导图并写入 `.mtn.md` 顶层 `layoutMode`。新建导图复制全局“默认布局”的当前值；之后修改全局默认值不会重排或改写已有导图：

| 布局 | 规则 |
| --- | --- |
| 均衡 | 根节点居中，先按一级分支的完整子树高度从高到低分配到当前较空的一侧，首个分支从右侧开始；两侧内部恢复文档顺序。 |
| 向右 | 根节点在左，所有分支向右展开。 |
| 向左 | 根节点在右，所有分支向左展开。 |
| 树形 | 根节点位于顶部，按子树宽度从上向下排列。 |
| 放射 | 根节点居中，按叶子权重划分角度扇区，从根节点右侧开始顺时针沿圆周向外辐射。 |

主题通过同一设置菜单切换，只影响当前导图并写入 `.mtn.md` 顶层 `theme`。新建导图复制全局“默认配色主题”的当前值；之后修改全局默认值不会重绘或改写已有导图。

五种布局的几何规则以 MIT 许可的 Light Mindmap 为参考：横向布局普通层间距为 32 px，根节点到一级分支为 45 px，同级子树按完整包围尺寸保留至少 9 px 间距。放射布局最小半径步长为 90 px，径向安全余量为 23 px，角向余量为 9 px。实现仍使用本插件的动态文字测量与碰撞保护，长标题、标记、文件按钮及折叠控件不得因此重叠。

全局设置“思维导图 → 节点对齐”提供两种策略：

- **同级节点对齐（默认）**：同一深度共用列、行或放射半径。
- **紧凑布局**：子节点按父节点实际宽高就近放置，减少不同分支中短节点造成的空白；仍须保持节点不重叠。

### 5.4 左下角状态栏

状态栏固定在视图左下角且不随画布缩放。圆角矩形内部从左到右显示主题数、按稳定资源 ID 去重的关联文件数、树深度、复位画布按钮、保存按钮和手动扫描文件夹按钮。文件数包含 Markdown、图片、附件、Excalidraw 和其他思维树等所有文件引用，不包含网页 URL。主题数包含根节点；树深度按根节点为 0、一级节点为 1 计算。

复位画布将根节点置于画布中心、缩放恢复为 100%，并选中根节点。保存按钮与复位按钮使用相同的无边框纯图标样式，不显示文字；已保存时图标为绿色，存在未落盘修改或保存失败时为红色，点击可立即保存。保存按钮右侧的文件夹扫描按钮会清除本次扫描缓存并重新检查当前树所在目录；它遵循当前树的收集策略，“关闭”自动收集时手动点击仍显示候选列表，未发现新增文件时给出提示。

圆角矩形外部右侧依次放置两个独立的撤销、重做按钮，并按历史栈状态禁用。顶部工具栏不再重复提供撤销、重做。

### 5.5 节点视觉状态

节点至少包含以下状态：默认、悬停、选中、编辑中、拖拽中、拖拽目标、引用失效、只读。

思维树首先服务于阅读、理解和学习，内容层级必须始终高于操作控件。没有独立语义的按钮、图标和辅助控件默认使用低对比度、随 Obsidian 明暗外观自适应的中性灰；悬停和键盘聚焦也只增强灰阶对比，不借用节点或分支强调色。警告、删除、保存状态、进度、优先级、高亮和明确选中状态等需要传达具体含义的场景，才使用对应的语义强调色。

普通节点本体在鼠标悬停时保持完全静态，不缩放、不增亮、不增强阴影，也不播放相关过渡；折叠按钮显隐、选择虚线和拖放指示等具有明确操作语义的状态不受此限制。画布平移使用按设备像素比对齐的 `left/top`，内容缩放优先使用 CSS `zoom` 重新栅格化，节点布局坐标统一取整，避免长期 GPU 合成缓存和亚像素边界造成部分文字清晰度不一致。

- 节点使用三档文字尺寸：根节点字号/行高 `18/23px` 并保留 `32px` 最小高度；根节点直接子节点字号/行高 `16/20px`；二级及所有更深节点统一为 `13/17px`。一级及更深节点不设置固定最小高度，按文字行框和内部元素实际高度确定；所有层级均不设置固定最小宽度。
- 所有节点的标题内边距统一为上下各 `3px`、左右各 `5px`。布局分别保存“标题测量宽度 + 合计 `10px` 水平内边距”的标题区域宽度和包含尾部元素的完整节点宽度；图片主体使用相同外边距。标记、资源徽标及关联控件固定从标题区域右侧向屏幕右方扩展，不得反向移动标题锚点。文件和 URL 的打开控件均占 `22px`（`20px` 按钮 + `2px` 前置间距）；文件的“取消同步 + 打开”组合占 `44px`。只有实际存在尾部元素时才增加标题到首项的 `2px` 间隔，多个尾部元素之间同样间隔 `2px`，纯文本节点不保留隐藏间隔。
- 节点标题左侧不显示资源类型图标，避免无效视觉干扰。
- 所有关联文件和 URL 的节点在内部最右侧显示同一个灰色 `fa-share-square-o` 打开图标；文件按设置在新标签页或右侧竖向拆分中打开，URL 沿用现有浏览器打开行为。该图标保持静态，不提供悬停变色、悬停背景或 `title` 弹出提示；无障碍名称为“打开关联资源 / Open linked resource”。
- 取消文件名关联的节点在右侧显示同步关闭警告标志，但仍保留文件打开按钮和资源引用。
- URL 节点打开前校验 HTTP/HTTPS 协议，不显示文件名同步关闭标志；现有网页关联无需修改数据即可显示打开图标。
- 图片关联节点直接显示为“图片主体 + 底部标题、标记、资源徽标与打开按钮”。新图片按原比例适配在 `180×135px` 内且不放大小图；每个引用可通过右下角低强调灰色手柄独立调整显示宽度，范围为 `60–600px`，高度始终按原图比例计算。拖动期间临时重排节点与连线，松开时才形成一个撤销记录并保存，`Escape` 或指针取消恢复原尺寸。编辑标题时保留图片与节点外框，并将输入框放在底部信息行。
- 图片从关联路径异步加载；加载完成后的尺寸变化只原地重排并保持当前画布锚点。图片损坏、引用失效或超过解码安全上限时回退为普通关联文件节点。
- 有子节点且当前展开时，在分支向外生长的一侧使用固定尺寸的圆形减号按钮，不显示数量；当前折叠时，在同一位置使用等尺寸的圆形数字按钮，数字表示直接子节点数量并始终显示。两种按钮统一使用低对比度中性灰背景、边框和内容，不使用节点色、分支色、白色高对比文字或彩色阴影。减号按钮仅当节点被选中、鼠标悬停节点或按钮、或者按钮获得键盘焦点时显示。向右、向左、树形分别放在右、左、下方；均衡布局的后代继承所属一级分支方向；放射布局按相对根节点的主要向外轴放在上、下、左或右。节点与按钮间的空隙不得导致移动鼠标时按钮闪退，拖拽时两种按钮均隐藏。
- 引用失效时显示警告图标，但保留节点标题、路径快照和修复入口。

内置主题包括活力（默认）、经典、清新、海洋、日落、午夜、石板、素净、素雅和浮光。颜色取自 Light Mindmap 的十二色分支调色板，并为 Obsidian 深色外观保留适配背景。节点与画布背景全部使用纯色，不使用线性或放射渐变。所有主题、所有节点形状的节点容器均无实体边框；圆角及无边框的可见非叶节点使用 `2px` 圆角，方角使用 `0px`，“无边框”额外让普通叶子节点背景透明。选中虚线、拖放指示和资源徽标边框不受此规则影响。

所有主题都按根节点 `childIds` 的当前顺序为一级分支依次分配十二色，前十二个分支颜色不重复，第十三个开始循环；一级分支的所有后代连接线继承该分支颜色，调整一级节点顺序会同步改变颜色。前七套主题同时使用该分支色作为节点层级色。素净、素雅和浮光使用相同的灰阶节点与十二色连线：浅色画布为 `#F7F3E8`，根节点使用 Obsidian 强调色，一级节点为 `#4A4A4A`，二级及以后为 `#E2E0DB`；暗色画布为 `#1E1E1E`，一级节点为 `#484848`，二级及以后为 `#2E2E2E`。这三套主题的节点不继承分支彩虹色，只有连线使用所属一级分支的颜色；高亮标记仍可覆盖灰阶背景，选中和拖放轮廓统一使用 Obsidian 强调色。素净无阴影，素雅使用普通 `0 2px 6px / 10%`、根节点 `0 4px 12px / 14%` 阴影，浮光使用普通 `0 6px 18px / 20%`、根节点 `0 10px 28px / 24%` 阴影。

主题不仅改变颜色，还携带默认连线形状、虚实、端点、透明度和阴影；实际描边宽度统一为 `1px`：

| 主题 | 默认连线 |
| --- | --- |
| 活力 | 平滑实线并带轻阴影。 |
| 经典 | 低阴影的直角实线，方形端点。 |
| 清新 | 较轻的平滑实线，圆形端点。 |
| 海洋 | 平滑虚线，使用 `7 5` 节奏。 |
| 日落 | 平滑实线与暖色轻阴影。 |
| 午夜 | 发光感直角虚线，使用 `6 4` 节奏。 |
| 石板 | 直线、方形端点且无阴影。 |
| 素净 | 圆头平滑实线；节点无阴影。 |
| 素雅 | 圆头平滑实线；节点使用轻阴影。 |
| 浮光 | 圆头平滑实线；节点使用强阴影。 |

每棵树的“连线样式”默认选择“跟随主题”，也可强制平滑、平滑虚线、直线、直角或直角虚线，并以顶层 `connectionStyle` 写入 YAML；全局选项只决定新建树以及缺失属性文件的默认值。强制选项只覆盖路径形状与虚实，主题自己的透明度、端点和阴影仍然生效；所有主题、深度和形状的实际描边宽度固定为 `1px`。平滑使用三阶贝塞尔曲线；树形布局优先使用纵向控制点，其余方向按节点边缘锚点连接。节点形状只保留圆角（默认）、方角和无边框；当前选择随每棵树保存，全局选项只是新建树的默认形状。历史 `capsule`、`sketch` 设置值打开时自动规范为圆角，并按现有无效属性流程标记待保存。

## 6. 详细交互设计

### 6.1 打开导图

插件必须在 Obsidian 创建文件视图前，将 `.mtn.md` 的 Markdown 打开请求直接路由到思维导图视图；不得先显示 Markdown 再执行视图切换。

打开 `.mtn.md` 时按以下顺序处理：

1. 读取 YAML Frontmatter 顶层 `schemaVersion`、可选 `documentId`、`layoutMode`、`recursiveScan`、`collectionMode`、`theme`、`connectionStyle` 与 `nodeShape`；缺少文档设置时使用对应默认值补齐，再定位大纲后的压缩数据区，执行 Base64、gzip、JSON 和树结构校验。
2. 若机器数据有效，加载完整导图；若无效，以只读错误状态打开，不用大纲猜测结构，也不覆盖原文件。检查本机未决版本暂存后，才能启用编辑与自动收集。
3. 解析所有资源引用并标记未解析项；不因单个失效引用阻止导图打开。
4. 按当前树的 `collectionMode` 决定关闭扫描、显示批量处理弹窗、自动添加到一级末尾或自动添加到“收集”节点。
5. 首次布局完成后以 100% 缩放把根节点中心与可见画布中心精确对齐，并选中根节点。画布尺寸尚不可用（例如后台标签页）时先隐藏世界层，待视图可测量后直接完成定位再显示，不得闪现旧视口或默认偏移。平移和缩放只在本次打开期间保留，不写入导图文件。

新建和打开导图均执行上述根节点居中流程。路由到导图视图时不显示“思维树视图”等通用切换通知；标签标题从目标文件路径直接取得，在文件对象尚未附加到视图的短暂阶段也不得退回通用视图名称。

同一规范文件路径只保留一个导图标签。文件管理器、链接、菜单、关联文件和工作区恢复均复用已经打开的分栏或弹出窗口；即使请求新标签或拆分，也优先激活原标签。不同文件的打开位置仍遵循原设置，不通过 `documentId` 判断是否同一标签。

### 6.1.1 外部同步版本选择

- 仅外部压缩 JSON 的逻辑节点数据实质变化且与本地不同，才在原标签内显示双栏预览；干净会话同样需要选择。普通 YAML（包括六项树设置）、文件重命名、自动标题、大纲和正文不触发版本选择。
- 左栏为“当前版本”，右栏为“外部最新版本”。分界线中部两侧各有一个“保留此版本”按钮，没有默认回车选项。两栏统一使用最新 YAML 设置，属性变化不使节点版本选择失效；后台标签不会抢焦点。
- 两栏可以独立平移、缩放和临时展开/折叠，不允许编辑、拖入、关联、删除或图片缩放。临时折叠不影响最终保留的版本。首次适配范围，外部再次刷新保留右栏视口。
- 当前版本包含尚未确认的标题草稿；预览期间暂停所有修改、自动保存和目录收集。草稿不触发文件改名，只有保留当前版本后才继续原有同步流程。
- 外部继续修改时持续重读右栏。点击按钮后若逻辑版本已变化，则刷新并提示重新选择；仅正文改变不要求重新选择，并使用最新正文保存。
- 每次仅选择整份机器数据，不做节点级合并，也不回退最新属性。当前版本保留撤销历史，外部版本清除旧历史；外部属性同步到历史快照，防止撤销节点时恢复旧属性。完成后恢复原画布，不主动复位视口。
- 误删或修改已有 `documentId` 时显示独立安全提示，列出原值与现值，提供“恢复原 documentId”和“重新检查”，不显示无法点击的两个版本按钮。恢复前校验重复身份，原 ID 被其他文件占用则列出路径并停止；恢复仅修改身份属性，读回成功后无 JSON 变化则恢复原会话及未确认草稿，有 JSON 变化才进入双栏选择。
- 在 Obsidian 属性面板删除导图设置后，运行时采用默认值但文件保持缺失；普通保存、重开或撤销节点不会补回。之后在树菜单主动设置该项才重新写入。属性更新不打断编辑框和输入法。暂存、格式或磁盘错误明确显示原因与重试入口。
- 未决当前版本、基线、草稿及提交回执保存在插件目录 `pending-conflicts/<本机标识>/`，写入并读回校验后才允许选择。关闭或重启不等于选择，重新打开继续预览最新外部文件。暂存失败、文件消失、危险身份变化、损坏或未来格式会阻止覆盖并提供重试。
- 选择成功且验证通过后清理对应暂存。不再创建、扫描或提醒旧 Recovery 文件；已经存在的文件不读取、不迁移、不删除。压缩 JSON 中保存孤立节点的小写 `recovery` 字段保持不变。

`.mtn.md` 的实际文件名是标签名称、文档标题和根节点标题的权威来源。通过 Obsidian 或其他插件复制、重命名文件后，打开视图时必须按新文件名同步根节点；文件已打开时收到 Vault 重命名事件后立即同步。编辑根节点标题则反向重命名 `.mtn.md`。默认生成的一级标题随之更新，用户自行添加的其他 Markdown 说明不受影响。

“同目录文件”默认排除：当前 `.mtn.md`、其他 `.mtn.md`、隐藏文件、插件配置目录，以及全局设置中命中的忽略规则。是否递归扫描由左上角设置菜单按树控制，默认不递归。

打开时不解析或导入大纲区。插件不提供打开导图源文件的按钮或命令；若文件被外部工具修改，画布仍以有效 `schemaVersion` 与底部压缩数据区为准，可选 `documentId` 只参与资源关联，并在下一次保存时覆盖大纲区。

### 6.2 同目录文件收集

确认收集后，画布现有提示层立即显示低强调灰色进度；自动收集及手动扫描使用同一流程，期间禁用重复收集。进度与保存按钮状态独立，校验过程中不显示未验证节点。处理完成后按原顺序整批插入成功项、立即重绘并产生一次撤销，不等待保存或后续元数据通知。已经被其他操作关联的文件不重复添加；全失败不产生撤销，部分失败汇总路径与原因。切换文件、关闭视图或进入版本冲突时终止后续提交、清除进度，不向其他导图插入节点；当前选择和画布锚点保持不变。

通过 `Ctrl/Cmd+E` 创建笔记时，同一节点的重复按键共享当前请求，文件创建及关联各执行一次。若文件已经创建但最终无法关联，提示保留文件的完整路径，用户可在问题解决后通过“关联已有文件”接回，不自动删除该笔记。

每棵树以顶层 YAML `collectionMode` 保存以下策略，全局“思维导图 → 默认文件收集策略”只初始化新树：

- **关闭**：不扫描、不提示，也不修改导图，可把 `.mtn.md` 当作纯粹的思维导图使用。
- **每次询问**：扫描后显示一个可多选列表，而不是逐个弹窗，并允许选择以下本次动作。
- **添加到一级末尾**：自动把全部候选按当前顺序追加为根节点的直接子节点。
- **添加到收集节点**：自动加入唯一的“收集”一级节点，不存在时先在一级末尾创建。

“每次询问”的弹窗提供：

- **添加到第一层末尾**：按当前列表顺序追加为唯一根节点的直接子节点。
- **添加到【收集】节点**：不存在时在根节点的子列表末尾创建唯一的“收集”节点，再追加到其末尾。
- **本次忽略**：当前打开周期内不再提示，下次打开仍会出现。

弹窗应允许全选、取消选择、按类型筛选，并显示目标位置预览。用户关闭弹窗等同于“本次忽略”，不修改文档。

文件是否“已关联”按稳定资源 ID 判断；索引尚未建立时退回到规范化路径判断。

候选文件尚无稳定 ID 时，弹窗必须提示本次加入将修改 Markdown Frontmatter，或给非 Markdown 文件追加 `~mtn-<短ID>` 文件名后缀；只有用户确认加入的文件才执行该变更。

### 6.3 选择与编辑

- 单击节点：选中节点。
- 双击节点标题或按空格键：进入标题编辑；空格键进入时不全选文字，光标放在标题末尾。
- 标题输入框使用中性实色、无边框、无圆角的紧凑浮层；编辑草稿完整保留前导、尾随和连续空格，空格必须立即推动光标并参与输入框宽度与换行计算。草稿按当前文字实时采用与节点相同的实际字体测量，达到全局换行宽度后向下增高；显式换行作为硬换行且空行计入高度。输入期间节点外框、整树布局和连线保持不变，确认或取消后才执行一次正常布局；确认时继续裁掉绝对首尾空格并保留内部空格。浮层可临时覆盖邻近内容。双击切换到另一节点时先提交上一输入框，并以输入框自身节点 ID 校验失焦保存，旧标题不得写入新节点。
- `Enter`：编辑时确认标题、退出编辑并立即保存；非编辑时直接在下方添加同级节点。
- `Shift + Enter`：非编辑时在所选节点上方添加同级节点；标题编辑框内与 `Enter` 一样只确认并保存标题。
- `Tab`：非编辑时添加子节点；在标题编辑框中按下时只确认当前标题并返回画布，下一次独立按下才创建子节点。
- `Shift + Tab`：非编辑时在所选节点与原父节点之间插入一个父节点；编辑时只确认标题，下一次独立按下才插入父节点。对根节点使用时创建新根节点。
- `↑` / `↓`：只移动选择焦点，不修改结构；按持久 `childIds` 顺序选择上一个或下一个兄弟节点，到达同级边界时保持不变。
- `←` / `→`：只移动选择焦点，在父节点与第一个子节点之间导航。向右布局和树形布局以 `→` 进入第一个子节点、`←` 返回父节点；向左布局反向；均衡和放射布局按当前一级分支所在根节点左/右侧决定方向。折叠节点不把焦点移入不可见子节点。
- `Ctrl/Cmd + ↑` / `Ctrl/Cmd + ↓`：将主选节点与上一个或下一个同级节点交换位置；根节点和同级列表边界不执行移动。
- `Ctrl/Cmd + E`：为未关联资源的所选节点创建 Markdown 笔记；节点已有文件或资源时显示提示且不覆盖原关联。
- `Ctrl/Cmd + S`：立即保存当前思维导图，并根据最新节点数据重建 Markdown 大纲；若正在编辑节点标题，先提交输入框中的文字再保存。
- `Space`：编辑节点标题。
- `Delete` / `Backspace`：打开所选分支的删除对话框。
- `Esc`：取消编辑、清除拖拽预览或关闭弹窗。
- `Ctrl/Cmd + A`：画布聚焦时选择所有可见节点；文本编辑时保持系统默认行为。
- `Ctrl/Cmd + C`：复制所选分支；多选时复制所有最上层选中分支及其后代，并保留资源关联。
- `Ctrl/Cmd + X`：剪切所选分支；只有系统剪贴板写入成功后才从当前导图删除节点，不删除关联文件。根节点本身受保护，不能被剪切。
- `Ctrl/Cmd + V`：优先粘贴插件内部的结构化导图分支；外部单行文字或 URL 直接创建节点，多行文字进入预填导入窗口。当前活动导图在文档捕获阶段接收粘贴，首次事件未提供纯文本时立即读取系统剪贴板兜底，不要求先在其他位置粘贴；节点编辑框、弹窗及其他可见文本控件仍使用系统原生粘贴。
- `Ctrl/Cmd + Z`、`Ctrl/Cmd + Shift + Z`：撤销、重做。
- 在画布空白区域按住左键拖动：显示选择框，并在拖动过程中实时显示与选择框相交节点的选中效果；节点离开范围时立即取消本次框选产生的选中，松开左键只结束手势。按住 `Ctrl/Cmd` 时，实时框选结果与手势开始前的选中集合合并。
- 按住 `Ctrl/Cmd` 点击节点：切换该节点的多选状态。
- 在画布空白区域按住右键拖动：平移画布；拖动超过系统点击阈值后不得再弹出画布或节点菜单。
- 在画布上滚动鼠标滚轮：上下移动画布；按住 `Shift` 滚动时改为横向移动。只有按住 `Ctrl/Cmd` 滚动时才以当前鼠标位置为中心缩放，每次放大或缩小 10 个百分点。工具栏加减号仍使用相同的固定缩放步长，并优先以鼠标最后停留的画布位置为中心。
- 从 Obsidian 文件列表、搜索结果等位置把仓库文件拖到节点本体时，在该节点下新增关联子节点；拖到同级节点之间或首尾外延触发区时按指示位置插入；拖到其他画布空白处时添加到根节点下。仓库内文件只建立引用，不复制原文件。
- 从系统资源管理器拖入文件时，先按 Obsidian 附件目录规则复制到当前仓库并生成不冲突路径，再新增节点并关联副本；支持一次拖入多个文件，单个失败不影响其他文件。
- 右键单击节点：打开节点菜单，不触发画布平移。
- 触摸设备在画布任意位置普通单指滑动（包括从节点上开始）：平移画布，不移动节点。点按节点选中；同一节点在 300ms 内、触点相距不超过 24px 的两次点按进入原地编辑。
- 节点长按 450ms 后以现有虚线显示选中：直接松手打开节点菜单；移动超过 8px 后开始拖动节点。未达到长按时先移动超过 8px 则始终平移画布。阈值按屏幕 CSS 像素计算，不随缩放变化。根节点不可拖动。
- 双指移动/捏合以两指中点为锚点，连续平移和缩放，范围 20%–300%，不使用 10% 分档；鼠标滚轮和加减按钮仍使用原有 10% 步长。第二根手指加入会取消未提交的节点拖动或图片缩放；减少为单指后继续平移，不重新触发点按或长按。
- 折叠/打开按钮保持点按操作，图片手柄可直接拖动缩放；触摸菜单仍复用所有添加、关联、删除和移动文件功能。不新增触摸多选或惯性滑动，外接键盘多选继续可用。
- 从画布内开始的手势不应同时触发 Obsidian 侧栏或下拉快速操作；画布外的宿主界面、菜单和原生输入控件不被接管，不尝试禁用 iOS 系统级屏幕边缘手势。
- 移动端原地编辑同步聚焦，保留输入框内原生选词、光标和粘贴。只依据可观测的可视区域遮挡做最小画布避让，保留 12px 安全距离，不改变缩放；结束编辑及键盘收起后移除自动偏移，用户主动导航则取消自动复原。编辑仍冻结树布局，并复用共享草稿与确认保存流程。
- 节点文字左对齐；同级对齐模式以标题区域左侧作为共用列锚点，紧凑模式不强制无关分支成列，但尾部元素同样不能反向推移自身标题。全局设置的“节点文字换行宽度”只限制标题文字区域；标记和文件按钮在该宽度之外向屏幕右侧扩展完整节点，不得挤窄文字或使文字提前换行。碰撞检测和连线仍使用完整节点矩形，文件名同步时换行会转换为空格。
- 连续数字、长英文单词和无空格标识符必须允许在任意字符处断行，不得超出节点边界。画布只渲染统一文字测量器确定的分行，根节点独有的字距及当前字体属性必须参与宽度与高度计算，不能再由 CSS 产生布局未计入的额外换行。
- 节点只保留较小的文字内边距和层间距，使同屏内容更紧凑。
- 普通选中和标题编辑中的节点均使用同一套虚线外框。通过 `Tab`、`Enter` 或工具栏新建并进入编辑的节点不得通过缩放、发光或放大表示焦点；编辑状态不改变节点尺寸。

左键从节点内部开始拖动时仍执行节点排序/改变层级，不触发框选；左键框选只从画布空白区域开始。右键平移过程中应阻止浏览器原生上下文菜单。

所有结构修改进入统一命令栈，支持 `Ctrl/Cmd + Z` 和 `Ctrl/Cmd + Shift + Z`。保存成功后仍保留当前会话内有限数量的撤销记录，默认 100 步。

### 6.4 新增节点

- **添加子节点**：追加到当前节点子列表末尾并立即编辑标题。
- **添加兄弟节点**：追加到当前节点之后；根节点不允许添加兄弟节点。
- 未选中节点时，工具栏“添加”会在根节点的子列表末尾创建节点。
- 新节点默认标题为“未命名节点”（英文界面为 “Untitled node”），创建后立即全选标题进入编辑。编辑中的 `Enter`/`Tab` 只确认标题，退出编辑后再次独立按键才创建节点；长按产生的系统自动连发不会批量创建。
- 清空标题并确认或失焦时恢复为本地化的默认标题，不再因空标题自动删除节点。
- 每份导图必须且只能有一个根节点。根节点是整棵树的结构入口，对应当前导图所组织的文件夹；不能被删除、拖拽或转换为其他节点的子节点。

### 6.5 拖拽排序与改变层级

拖拽时显示明确的三种落点：目标节点之前、目标节点之后、目标节点内部。鼠标位于节点矩形内时始终判定为“内部”；位于两个同级节点之间的空隙时判定为中间插入。第一个节点之前和最后一个节点之后按相邻间隙大小设置类似的外延触发区；树形布局沿水平方向判断，其余布局优先沿垂直方向判断。

- 放到“内部”时，节点追加到目标节点的子列表末尾。
- 开始拖动后，以半透明浮层让鼠标按住的单个节点跟随指针；指针始终位于浮层的几何中心，不保留初始按下位置的偏移。多选时浮层仍只显示鼠标按住的一个节点，但原位置会临时隐藏全部实际移动分支及其后代和连线，并继续保留布局空间。
- 鼠标按住的节点属于当前多选集合时，实际移动全部选中节点；否则只移动按住的节点。选中集合同时包含祖先与后代时只移动最上层选中分支，以保留该子树内部连接；来自不同子树且父节点未被选中的顶层分支，统一按当前树顺序插入目标位置，成为同一层兄弟节点。
- 禁止把节点移动到自身或自身后代中。
- 根节点不能作为拖拽源；其他节点只能被移动到根节点之下。
- 拖动集合中的任一分支都不能放入其自身或其后代；一次多节点移动作为单个可撤销命令提交，不允许出现只移动部分分支的中间状态。
- 折叠节点可作为“内部”目标，但不会自动展开；悬停 800 ms 后可临时展开。
- 每次拖拽是一次原子操作，可一步撤销。

### 6.6 右键菜单

按以下分组排列：

**内容与关联**

- 已关联文件时，第一项显示“取消关联”或“恢复关联”；这里只控制节点名与文件名同步，不移除资源引用。
- 只有未关联资源时显示“添加笔记”“从模板添加文件”“关联已有文件”和“链接网页”；已关联任何文件或 URL 时均隐藏这些入口。
- 已关联节点依次显示“打开资源”→“使用默认应用打开”（仅桌面端，`app-window` 图标）→“移除关联”。
- “移除关联”保留节点和真实文件，只清空资源引用及标题同步状态；完成后才可重新关联。第一项“取消关联”仅关闭文件名同步，不能借此更换资源。

此分组不提供打开当前导图源文件的入口。“打开资源”只针对当前节点主动关联的笔记、其他思维树、附件或 URL。

菜单绑定打开时的视图会话、节点及资源身份；点击时如果视图切换、节点删除或关联变化，取消旧操作并提示重新打开菜单。文件重命名/移动不改变身份，仍可从最新路径打开。

“使用默认应用打开”将仓库文件交给操作系统为该格式配置的应用，将 HTTP/HTTPS URL 交给系统默认浏览器。只在桌面应用中提供，移动端不显示此项。现有“打开资源”和节点尾部图标仍保持原打开方式与设置，不受新入口影响。文件缺失、系统打开失败或当前仓库无法提供本地路径时只提示错误，不回退到其他打开方式，不改变文档、撤销历史或视口。

**结构**

- 添加子节点。
- 添加兄弟节点。
- 折叠 / 展开。
- 折叠所有子分支 / 展开所有子分支。
- 删除分支（当前节点及全部后代）。
- 仅删除当前节点（子节点迁移到当前节点所在层级，并占据原节点位置）。

**组织**

- 标记。
- 删除操作下方用分割线隔开“将关联文件移动到”；分支没有任何文件引用时禁用，只有 URL 引用也视为没有可移动文件。

“标记”与顶部工具栏按钮打开同一个图标面板。面板按进度、优先级、高亮排列；每个类别的名称和独立删除按钮位于同一行，图标选项从下一行开始且不显示文字。每个类别最多选择一个值，类别删除按钮只清除该类别，不影响另外两个类别。进度与优先级图标显示在节点标题后方但不进入标题字符串；高亮只改变节点背景，不在节点中增加图标。所有类别都写入压缩 JSON 的节点 `markers` 属性，并以可读后缀同步到大纲。关联其他 `.mtn.md` 文件时，节点尾部自动追加淡绿色“思维树”圆角徽标，并以 `〔mind-tree〕` 同步到大纲；关联文件的 Frontmatter 包含 `excalidraw-plugin: raw | parsed` 时，在打开按钮之前追加无边框、紫色填充和白色文字的“绘图”徽标，并以 `〔excalidraw〕` 同步到大纲。文字型资源徽标统一使用 `10px/600` 字体、`12px` 行高和四周 `2px` 内边距，宽高按实际渲染内容测量。

关联文件在没有“思维树”或“绘图”专用徽标时使用低强调中性灰扩展名徽标。先从文件名移除当前 5 位资源 ID 或历史 `~mtn-` ID，再从末级后缀向左逐段提取：每段只允许英文字母和数字，点仅作分隔；遇到含下划线、连字符、加号、中文、空格或空段时立即停止，保留已取得的合法末尾后缀。不截取非法段中的局部字符，末段不合法时不显示标签，也不纳入第一个有效点之前的文件名主体。保留现有 64 字符上限；非 Markdown 后缀默认转为大写，例如 `资料.chapter_one.pdf` 显示 `PDF`、`资料.chapter_one.tar.gz` 显示 `TAR.GZ`、`report.v2.pdf` 仍显示 `V2.PDF`、`report.p_df` 不显示。Markdown 文件（包括 `.plugin.md` 等插件复合格式）参与别名匹配，但仅在匹配到别名时显示标签，未匹配时仍隐藏，不默认显示 `MD` 或 `PLUGIN.MD`。无扩展名文件和只有前导点的隐藏文件继续不显示。

基础设置中的忽略与别名配置及输入校验保持不变，不因自动提取规则收紧而改写已有规则。匹配忽略大小写和开头的点，以新提取的完整后缀优先、末级扩展名兜底，忽略优先于别名。例如 `笔记.plugin.md` 优先采用 `plugin.md` 别名，其次采用 `md` 别名；配置 `md → 笔记` 也会为普通 Markdown 显示“笔记”标签。处理顺序固定为“专用徽标 → 提取扩展名 → 忽略规则 → 别名 → 默认显示”；“思维树／绘图”专用徽标不受任何通用别名或忽略规则影响。扩展名徽标由路径与全局设置实时派生，只显示在画布和 PNG/SVG 导出中，不写入节点 `markers`、压缩 JSON 或大纲；修改规则立即刷新已打开导图，保持选择、缩放和画布锚点，不产生文档修改或撤销记录。

**复制与导出**

- 复制为 Mind Tree 分支。
- 复制为 Markdown 无序列表。
- 复制为 PNG（P1）。
- 导出分支为 PNG 文件。

危险操作与普通操作视觉分组。“删除分支”始终打开专用对话框，不允许绕过确认。

### 6.7 创建与关联文件

#### 添加笔记

1. 以节点标题生成合法文件名，默认目录为当前导图所在目录。
2. 文件名为空、包含非法字符或冲突时，在创建弹窗中提示并要求修正；不静默覆盖现有文件。
3. 普通新笔记的正文只使用“主题笔记 → 新笔记默认填充内容”中保存的 Markdown，并原样保留换行、缩进和空白；节点标题只用于文件名，不自动写入 `# 节点名` 或其他正文。设置为空时不生成正文。
4. 创建成功后在 Markdown Frontmatter 中写入稳定 `resourceId`，建立资源索引，并将节点设为双向标题同步；默认内容已有合法 Frontmatter 时合并资源属性，不删除原属性。
5. 若节点尚无标题，先要求输入文件名，并以不含扩展名的文件名作为节点标题。
6. 创建成功后按“思维导图 → Ctrl/Cmd+E 新文件打开位置”选择右侧拆分、新标签页、当前标签页或新窗口；默认使用右侧拆分。

文件节点默认启用节点名与文件名双向同步，包括新建笔记、关联已有文件和同目录收集的 Markdown、图片与附件：

- 在导图中修改节点标题，会请求重命名对应文件。
- 文件在 Obsidian 或其他插件中被重命名后，所有双向同步节点的标题随之更新；即使 Obsidian 的链接改写重新载入了旧压缩快照，也必须在渲染和保存前根据稳定资源 ID 与规范文件名重新校正，不能短暂更新后恢复旧标题。
- 若重命名会覆盖文件、违反系统规则或文件处于不可写状态，则取消本次重命名并恢复标题，同时给出原因。
- 用户可通过右键菜单第一项“取消关联”关闭单个节点的名称同步，之后节点标题作为独立显示名，并显示同步关闭标志；外部文件重命名只更新资源路径，不覆盖该独立标题。
- 选择“恢复关联”时，以当前节点标题重命名关联文件；冲突时保持关闭状态并给出原因。
- 非 Markdown 文件重命名时保留 `~mtn-<短ID>` 后缀和原扩展名。

#### 从模板添加文件

1. 节点未关联资源时，在右键菜单“添加笔记”下方显示“从模板添加文件”。
2. 打开可搜索对话框，列出模板目录及子目录中的全部仓库文件，包括普通 Markdown、图片、PDF、压缩包、Canvas、Excalidraw、`.mtn.md` 和无扩展名文件；未配置目录或没有模板文件时给出提示。
3. 选择模板后通过 `Vault.copy()`，将副本写入“新笔记目录”；该设置为空时写入当前导图所在目录。副本以节点标题命名，普通文件保留末级扩展名，思维树保留完整 `.mtn.md`；无扩展名文件不补 `.md`。重名时生成唯一名称，不覆盖既有文件。
4. 只复制所选文件，不分析、复制或改写其内部链接，也不展开模板变量、不追加“新笔记默认填充内容”。源模板始终不修改，二进制副本不进入文本或 Frontmatter 处理。
5. 只替换副本的插件关联身份：普通 Markdown 写入新的 `mind-tree-nature.resourceId`，保留其他属性和正文；`.mtn.md` 只写新的顶层 `documentId`，不改压缩区和内部引用；非 Markdown 文件内容不变，文件名使用新的五位 ID 和当前 `@`/`%` 分隔符，不继承模板的新旧 ID。
6. 按副本实际类型建立资源引用，图片显示为图片节点，Excalidraw 保留 Frontmatter 识别属性，其他文件沿用文件类型标签。节点标题通过现有文件标题转换规则隐藏资源 ID，标题同步使用现有全局默认值。
7. 选择器打开时捕获目标视图会话及节点；复制前、复制后和提交前检查目标仍存在且未被关联，不能把文件挂到切换后的导图。创建或身份处理失败、目标失效时，只将尚未关联的新副本移入回收站并清理索引；回收失败明确提示副本路径，不误删源文件、既有文件或同路径替换文件。
8. 成功关联只提交一次领域命令，并沿用“Ctrl/Cmd+E 新文件打开位置”打开副本。自动打开失败时保留副本与关联，只提示打开失败；撤销节点关联也不自动删除已成功创建的文件。

#### 关联已有文件

- 使用模糊搜索框检索仓库中的全部文件，排除当前视图自身的 `.mtn.md`，但允许人工关联其他思维树文件。
- 选中文件尚无稳定身份时，按文件类型补写 Markdown Frontmatter、思维树 `documentId` 或非 Markdown 文件名短 ID，再建立节点引用。
- 不提供替换现有关联的路径；必须先“移除关联”，再为未关联节点选择新的文件或网页。
- 同一文件允许被多个节点或多份导图引用。

创建笔记、模板创建及文件/网页关联统一捕获目标会话和节点，在入口、弹窗提交、异步操作完成及领域草稿提交前检查节点仍存在且没有资源。另一视图抢先关联或当前视图切换时，不覆盖已有标题或资源，也不提交错误导图。关联已有文件失败不删除文件；普通笔记已创建但目标失效时保留笔记并提示路径；未关联模板副本继续按模板回收规则处理。

#### 关联网页

- 必填合法的 `http` 或 `https` URL，可选自定义标题。
- 未填写标题时先使用主机名；首个版本不主动联网获取网页标题或图标。
- 拒绝 `javascript:`、`data:` 等可执行或内联协议。

### 6.8 移动关联文件

“将关联文件移动到”打开文件夹搜索框。搜索框下方提供可点击的“移动到当前文件夹”，点击后填入当前导图所在文件夹路径；匹配结果只包含仓库中已经存在的文件夹。弹窗底部提供：

- **仅移动当前节点的文件**：移动当前节点直接引用的仓库文件；当前节点未关联文件或只关联 URL 时禁用。
- **移动该分支内全部关联文件**：移动当前节点及全部后代直接引用的 Markdown、图片、附件、Excalidraw、其他思维树及任意仓库文件；纯文本和 URL 节点跳过。

批量移动规则：

- 目标文件已存在时不覆盖，该文件记为失败并显示路径与原因。
- 通过 Obsidian Vault API 移动，以便其他插件和链接更新机制收到事件。
- 一个文件被分支中多个节点引用时只移动一次。
- 部分文件失败时保留成功结果并显示逐项报告。
- “移动该分支内全部关联文件”只移动节点直接关联的文件，不改变导图节点层级。
- 文件正文中引用或嵌入的其他文件不在移动范围内，也不进行递归解析。

### 6.9 删除

- **删除分支**：选中根节点时禁用；其余节点始终先打开删除对话框。
- `Ctrl/Cmd` 多选后，键盘删除和所选节点的右键删除均覆盖全部选中节点。父分支与其后代同时选中时只计算、删除父分支一次；根节点自身始终保留，但不阻止删除同时选中的其他节点。
- 对话框第一行显示警告 Callout；第二行以左右两栏分别显示主题数和去重后的关联文件数，悬停或键盘聚焦时通过页面级浮层显示对应标题、路径的完整列表。浮层可延伸到对话框边框之外，不参与或挤压对话框内部布局。
- 详情列表仅由对应统计块触发，同时最多显示一个；鼠标移出统计块立即关闭，即使点击后焦点仍留在统计块也不延长显示。列表自身不参与悬停判断、不接收鼠标事件，不遮挡底部按钮交互；键盘 Tab 聚焦仍可查看，失焦关闭。
- 详情浮层保留最高 230px 的可视范围。鼠标停留在统计块上时，滚轮滚动对应长列表；列表到顶或到底不向底层窗口继续滚动，短列表不额外接管滚轮。同一次弹窗内两份列表分别保留滚动位置，关闭弹窗清理浮层、监听及相关计时器。
- 最后一行提供四个独立按钮：取消、删除主题和文件（红色）、仅删除关联文件（浅红色）、仅删除主题（浅红色且默认聚焦，按回车直接执行）。
- **删除主题和文件**：关联文件通过 Obsidian 文件管理器移入回收站，然后删除当前主题及全部后代。
- **仅删除关联文件**：保留主题节点，删除能够解析的关联文件并清除对应资源关联；删除失败的关联保持不变并提示路径。
- **仅删除主题**：删除当前主题及全部后代，保留实际文件。这一操作作为默认选择。
- **仅删除当前节点**：右键菜单仍可删除当前节点，并把其子节点插入到原节点的位置、保持原有顺序；该操作同样先打开删除对话框。
- **解除关联**：只清除资源引用，保留节点与标题。
- 主题结构删除进入撤销栈；实际文件删除遵循 Obsidian 回收站策略，不属于导图撤销范围。

### 6.10 复制、粘贴、导入与导出

复制分支时同时写入两种剪贴板表示：

- `application/x-mind-tree-nature+json`：包含完整分支数据，用于插件内高保真粘贴。它是临时剪贴板交换格式，与 `.mtn.md` 底部经过 gzip + Base64 编码的完整文档数据区相互独立。
- `text/plain`：Markdown 无序列表，用于普通编辑器、聊天工具和 AI。

粘贴规则：

- 在导图视图中粘贴自有 JSON 时保留结构、笔记关联、同步状态与其他节点属性，但为所有节点生成新 UUID，避免同一文档内 ID 冲突。若当前 Obsidian WebView 不允许写入自定义 MIME，插件在当前运行会话内使用与纯文本内容严格匹配的内存副本完成同样的高保真粘贴。
- 剪贴板同时含图片与文本时优先处理图片。图片 Blob 按剪贴板顺序写入当前导图所解析的 Obsidian 附件目录，再在同一父节点下创建连续兄弟节点；匿名图片使用带时间戳的 `Pasted image` 文件名并根据安全 MIME 补全扩展名。多图完成后选中并居中最后一个节点。图片只保存为仓库实体文件引用，不把 Base64、Object URL 或 `app://` 地址写入导图。
- 粘贴监听只由当前活动思维树处理；隐藏标签页残留的编辑器焦点不会吞掉操作，可见输入框则始终保留原生粘贴。事件内没有 `text/plain` 时，在同一次操作中读取系统剪贴板；读取失败时提示重新复制，空剪贴板静默忽略。
- 外部文本先统一换行格式并对整段内容执行 `trim()`；清理后不再含内部换行时直接创建子节点，使用与导入相同的 Wiki、Markdown 文件及 HTTP/HTTPS 链接规则。复制源附带的首尾空格、Tab 或换行不会把单行文字误判为多行；单行直接粘贴不移除列表标记或解析标题层级。
- 外部多行纯文本不直接创建节点，而是打开已预填内容的导入窗口；窗口默认选择第一项“列表 / 缩进文本”，用户可直接导入或切换规则。
- 外部工具对 Markdown 无序列表的修改不会改变导图；下一次保存会由机器数据重新生成大纲区。
- 选中节点时粘贴为其子节点；未选中或选中根节点时，粘贴到根节点的子列表末尾。

文本导入规则：

- “列表 / 缩进文本”允许在同一输入中混用无序标记、有序标记和普通文本行；列表标记被移除，空格或 Tab 的相对缩进决定层级，每个非空行按下述链接规则创建一个或多个节点。
- “多级标题”按 `#` 至 `######` 建立主层级；标题跳级时连接到最近的较低级标题，不创建占位节点。标题之间可混用无序、有序列表，顶层列表项成为最近标题的直接子节点，嵌套项按空格或 Tab 缩进形成后代；新标题会结束上一段列表。每个非空正文行成为最近标题的直接子节点并结束前一个列表分支，首个标题之前的列表按自身缩进形成顶层分支。
- 两种导入规则与单行直接粘贴共用行级链接解析：Wiki、Markdown 文件链接及 HTTP/HTTPS URL 均自动关联。只有一个链接时，用别名、显示文字或文件标题替换文件链接语法；裸网址及仅包裹网址的成对括号/尖括号被移除，以其余文字作标题。纯网址使用原网址，不联网获取页面名称。
- 一行包含多个链接时，按出现顺序生成多个独立关联的兄弟节点；重复链接也分别生成节点，同一个 Markdown 链接内的显示网址、目标及查询参数不会重复计数。链接外说明按原顺序合并为一个普通兄弟节点，放在第一位；仅用于分隔的空白、标点不另建节点。
- 拆分行之后的缩进子项、下级标题仅归该行生成的第一节点；存在说明节点时归说明节点，不复制子树。没有链接的行保持普通节点。
- 仓库链接以当前思维树路径解析，带文件路径的标题/块引用关联所属文件，普通笔记、附件、图片、绘图及其他思维树统一经过稳定身份关联；不新增标题/块定位字段。文件标题沿用全局同步规则，开启时以实际文件名为准（别名或说明可能被替换），关闭时保留导入标题；不为了匹配导入别名而重命名文件。
- 无法解析的文件链接保留其原始链接文字作为普通节点并汇总提示，不自动创建文件；重复身份冲突安全阻止本批插入。非 HTTP/HTTPS 外部协议、损坏语法保留文字，不作为仓库文件或网页打开；有效网址的查询参数、片段和百分号编码保持完整。
- 空行忽略；先按展开后的节点数、深度及文本体积上限校验，再完成整批资源解析并一次性提交，只占用一个撤销记录。文件目标在首次身份分配可能改变文件名前预先解析，重复路径复用结果。异步期间切换会话会取消操作，不向另一棵树插入节点。不追溯清理已有节点或内部结构化剪贴板中的标题，既有文件拖拽和图片粘贴不变。
- 导入结果作为当前所选节点的子节点，没有有效选择时添加到根节点下；完成后选中并居中第一个导入的顶层节点。

Markdown 导出映射：

```md
- 普通节点
  - [[notes/示例笔记|示例笔记]]
  - [Obsidian](https://obsidian.md)
  - ![[assets/example.png]]
```

PNG 导出默认包含选中分支的完整展开状态，不受当前折叠状态裁切；导出弹窗可选择透明/主题背景、1x/2x/3x 比例和内边距。图片节点会将安全图片数据嵌入导出结果，内部 SVG 渲染不引用仓库临时地址；SVG 图片先安全栅格化，无法导出的图片回退为标题与资源信息。文件名默认为节点标题，非法字符自动替换。


### 基础设置：本机资源索引

- “资源索引 → 重建索引”仅扫描并校验仓库文件身份，不改文件内容、名称或 ID，也不保存导图。
- 扫描时按钮禁用并显示进度；完成后显示索引数量、重复 ID 和读取失败数量，可展开具体路径。缓存存储不可用时提示仅使用内存。
- 重建原地更新资源显示，保持选择、视口、撤销及保存状态。重复身份不会自动修复，精确核对后的既有关联允许只读打开，新的关联及文件改写被阻止。
- 用户设置由 Obsidian 原生同步处理；接收外部更新不反向写回文件，正在输入的设置框延后到失焦再更新显示，不打断输入法。
