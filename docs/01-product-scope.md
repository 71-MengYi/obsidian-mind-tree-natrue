# 01 产品定位与范围

> 涵盖产品概述、核心概念、用户场景与功能优先级。  
> [返回文档导航](requirements.md)

## 1. 产品概述

Mind Tree Nature 是一个用于 Obsidian 的交互式思维导图插件。它以 `.mtn.md` 文件为载体，在自定义视图中组织笔记、文本、图像、附件和网页链接，同时保留可被普通 Markdown 编辑器与 AI 读取的无序列表大纲。

插件的核心价值不是替代 Markdown，而是为已有仓库增加一个可视化组织层：导图负责结构，Obsidian 文件仍然负责内容。

### 1.1 设计目标

- 在思维导图中快速创建、整理和打开 Obsidian 笔记。
- 用稳定引用降低文件重命名、移动后链接失效的概率。
- 同一份 `.mtn.md` 同时满足交互式编辑、Markdown 阅读和 AI 问答。
- 支持从同目录文件快速收集内容，并允许拖拽重组层级。
- 所有核心能力离线可用，不依赖第三方服务。
- 文件格式可恢复、兼容旧数据，并尽量避免插件升级造成数据损坏。

### 1.2 非目标（首个版本）

- 不实现多人实时协作或服务端同步；同步交由用户现有的 Obsidian 同步方案。
- 不实现通用画布、自由连线、流程图或任意图结构；首个版本只处理有序树。
- 不抓取、缓存或总结网页正文；URL 节点只保存标题、地址和可选图标。
- 不提供云端 AI 能力；AI 通过文档中的 Markdown 大纲理解结构。
- 不替代 Obsidian 的全文搜索、文件管理器和模板插件。

## 2. 术语与核心概念

| 名称 | 定义 |
| --- | --- |
| 导图文档 | 扩展名为 `.mtn.md` 的 Markdown 文件。 |
| 根节点 | 每份导图唯一的结构入口；不计入一级、二级、三级节点层级。 |
| 一级节点 | 根节点的直接子节点；二级及更深层级依此类推。 |
| 节点 | 导图中的最小结构单元，拥有稳定 UUID、标题、顺序和可选资源引用。 |
| 分支 | 一个节点及其全部后代节点。 |
| 资源 | 被节点引用的笔记、图像、附件或 URL。 |
| 文件索引 | 插件维护的仓库文件元数据及稳定资源 ID 映射。 |
| 大纲区 | `.mtn.md` 中可读的 Markdown 无序列表，是机器数据的可读投影。 |
| 压缩数据区 | `.mtn.md` 无序列表大纲之后保存完整节点状态的 gzip + Base64 数据块，是正常保存时的权威数据源；文件头保存版本、单树设置及首次跨文件关联后才产生的可选 `documentId`。 |
| 收集节点 | 用户选择“添加到【收集】节点”时承载新文件的一级节点。 |

## 3. 用户与典型场景

### 3.1 目标用户

- 使用 Obsidian 管理项目、研究资料或知识体系，希望通过树状结构整理笔记的用户。
- 希望让 AI 直接读取导图层级，但不希望依赖专有二进制格式的用户。
- 需要在桌面端与移动端查看同一份导图的用户。

### 3.2 核心场景

1. 用户新建导图，将同目录中尚未关联的笔记一次性加入导图。
2. 用户在节点上新建笔记，随后通过修改节点标题完成文件重命名。
3. 用户关联仓库中的任意已有文件或网页，并通过拖拽调整结构和排序。
4. 用户复制或剪切一个或多个分支，在另一份导图中高保真粘贴；也可以通过顶部导入窗口使用默认列表规则或切换到兼容嵌套列表的多级标题规则，将 Markdown 文本还原为层级，或将导图分支粘贴到普通 Markdown 文档中作为无序列表。
5. 用户把一个分支导出为 PNG，或复制图片到系统剪贴板。
6. 用户在普通 Markdown 阅读器或 AI 工具中读取自动生成的大纲；AI 工具在看到明确的压缩 JSON 忽略提示后无需继续分析，导图保存时会用机器数据重新生成大纲。

## 4. 功能范围与优先级

### 4.1 P0：首个可用版本

- 创建、打开、保存 `.mtn.md` 导图。
- 节点新增、重命名、删除、折叠、拖拽排序和层级调整。
- 关联任意已有仓库文件、创建新笔记、关联 URL。
- 图片文件以“图片主体 + 底部信息行”的节点直接显示；支持仓库/系统拖入、文件选择与剪贴板图片添加，并可按原图比例拖拽调整每个节点的显示尺寸。
- 同目录未关联文件扫描与批量处理。
- 文件索引及文件移动、重命名后的引用修复。
- 撤销与重做。
- 分支复制、剪切和高保真粘贴；列表/缩进文本与多级标题导入；外部单行文字直接粘贴；无序列表导出。单行粘贴与两种导入规则统一识别 Wiki、Markdown 文件链接和 HTTP/HTTPS URL；多个链接按出现顺序拆为独立关联的兄弟节点，说明文字单独保留。文件标题遵循全局同步设置；未找到文件时保留原始链接并提示。所有文件和网页关联节点使用同一个灰色打开图标。
- 导出 PNG 文件。
- 左键拖动画布空白区域框选，`Ctrl/Cmd` 点击切换多选，右键拖动画布空白区域平移画布；滚轮纵向平移，`Shift + 滚轮` 横向平移，`Ctrl/Cmd + 滚轮` 缩放。
- 多选节点后从任意已选节点发起整体拖拽；跨父级、跨深度选择会保留已选祖先内部的子树关系，其余顶层分支在目标位置组成同级节点。
- 节点使用根节点、一级节点、二级及更深节点三档字号和行高，只有根节点保留最小高度；节点文字左对齐，宽度按当前 Obsidian 字体和尾部元素的实际占用变化，达到全局阈值后换行并增加高度。
- 模板目录和扫描行为设置；支持均衡、向右、向左、树形和放射五种按树保存的布局。
- 全局切换同级节点对齐与紧凑布局；左上角快捷键帮助覆盖新增同级、子级、父级及 Markdown 笔记操作。
- 支持十套明暗自适应内置主题、按一级分支顺序循环的十二色映射、主题专属连线预设、五种按树保存的手动连线覆盖样式和三种按树独立保存的节点形状。
- 基础错误恢复与数据校验。

### 4.2 P1：增强版本

- 从模板目录及子目录复制任意仓库文件，包含图片、附件、Canvas、Excalidraw 和思维树；仅替换副本的关联身份，不处理内部引用。
- 附件节点的内容预览。
- 多选后的批量标记。
- PNG 复制到系统剪贴板。
- 进度、旗帜、数字优先级和 Emoji 标记。
- 导图内搜索、缩略图导航、适应画布。
- “将关联文件移动到”及包含子节点全部关联文件的批量移动。

### 4.3 P2：后续探索

- 用户自定义主题、更多节点样式和布局参数。
- 跨导图引用、只读嵌入和反向引用面板。
- 对外提供稳定命令/API，供其他插件调用。
